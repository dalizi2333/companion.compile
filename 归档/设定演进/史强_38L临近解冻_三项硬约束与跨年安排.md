# 《庄颜协议》：史强临近38-L复苏与三条人物硬约束

> 2026-10-17 **最高优先级时间线修订**。替代此前「危机纪元第5年治愈、后来在第6年38-L才办案」的错误过渡安排；舍弃「恰好冬眠两年」的精确笑点。正文尚未写，不动现有小说原稿。配套文件《24-52L_跨年恋爱_拆星米双重误读_史强招标错判_连续性.md》以本文件为准。

## 一、三个不可交换的硬约束

1. **史强刚入AI时代就参与案件**：他在消费级AI APP、肉包Agent全面普及前的**危机纪元第3年**入冬眠，此后直到**35-L拆网之后、38-L调查进入正式阶段前后**才因新的医学机会苏醒。在可工作之前必须完成治疗及医学评估，但首次获准恢复的实质性工作**立即就是PDC分配的罗辑相关安全/旧车祸复查**；不允许提早一年复苏、学习AI、办理其他案件后再遇罗辑。所谓「马上办案」，指**医疗许可后的第一份任务**，非刚出舱零检查、零治疗、立刻跨国搏斗。
2. **与罗辑没有原著式深交**：本作第3年之前双方至多认识名字、有限公务接触。史强没有替罗辑安置庄园、亲自找来庄颜、长期担任保护人；38-L是两人第一次较深入合作。史强不能靠私人交情主动接管面壁者保护事务，需有PDC正规授权。
3. **车祸旧案从未亲自参与**：第5年初罗辑遭ETO利用星米车机袭击，史强全程仍在冬眠。案发现场、证物保全、先期案情判断由其他PDC安保/刑侦人员完成。38-L史强第一次正式调阅卷宗，作为没参加过初侦的资深外部复核者寻找漏洞；不可写成他早先参与现场、提出「没有二次刺杀」判断或与嫌疑人交锋。

## 二、年份不再强行锁死史强复苏

| 时间 | 叙事事实 |
| --- | --- |
| 危机纪元第3年 | 史强白血病冬眠；新42-D（旧D30）同志顺带提到戴总认识的史强已入冻。此前40-D/41-D的2008年已有早期医学算法研究伏笔，但不存在可成熟救治史强的疗法。 |
| 危机纪元第5年 | 罗辑遭车祸（史强完全未参与侦查），入住北欧庄园并与庄颜从01-L到24-L逐步相爱、误会、化冰。史强仍冻眠。 |
| 24-L → 35-L | 可有数季到一两年生活跨度，具体年份不写死；35-L建议落第6年或其后，PDC供应链排查与罗辑亲自隔离全屋星米的联网设备。 |
| **35-L之后、38-L前后** | **新疗法达到史强的临床使用条件 → PDC出资安排解冻与治疗 → 医疗评估准许有限复职 → PDC立刻交办本案**。四步需要医疗过程但叙事上紧凑，38-L可用数个短时间标记展现，没有复苏后一整年适应AI的空窗。 |
| 43-S/L → 46 → 47—52 | 史强刚开始接触成熟Agent，仍不会亲手使用AI APP开展任务；靠后辈操作、自己判断证据，逐渐被克罗德秘密APP折腾，六连撞成为体能康复+刑侦经验的奇特实战。 |

**保留的笑点**：史强醒来问「这就治好了？」，本以为要睡几十/上百年，却只跨了几年；不强调精确睡了两年，更不以笑点为理由提前唤醒。**新技术提供者**仍是人择克罗得科研超算→独立实验室及医生验证→PDC高价采购治疗；克罗德APP研发、KILLER上线时序照旧。

## 三、35-L与38-L认知差：拆网不等于厂商涉案

- **罗辑**：从可取得的PDC企业档案、正常合同与安全记录，已经有充分理由认为星米不是人择/ETO控制的企业；保留技术审计，拆消费联网家居主要是物理/软件层面切断外部通信、观察庄颜是否依赖家庭云，并非公开定性星米有罪。对庄颜的深层观察原因暂不透露。
- **史强**：刚获准复职就看到整座庄园大量星米智慧屏、网关和智能家居被拆/隔离，加上自己初次调阅车机刺杀旧案，合理推测「罗辑/PDC莫非查到星米有问题」。罗辑说「主要为了断网」确实是实话，但省略了私人动机；史强察觉没说完也没错。
- **43-S/L**：史强查出无人工厂后续、星米发展独立AI骨干及与人择竞争，放下「星米是ETO外围」初步怀疑。**但对罗辑选供应商的心理判断仍然出错**：觉得他肯定不会让拆掉过、且车机曾被利用刺杀的星米中标。47—52六连撞便借这个误判运转，直到证据/招标结果纠正。

## 四、医学与动作尺度

- 本作安排架空的新疗法**真正治愈史强的白血病**，但疗法验证、术后评估/用药随访不可消失。允许以高强度科研支持缩短治疗流程，不能只写「克罗德算出来→当场治好→立刻执法」。
- 若38-L与35-L距离只有数天，可拉长38-L的内部时间或将医学准备/审批先完成，**只在临床条件允许解冻的阶段启舱**；复职时先做案卷复审和问询，六连撞逐步恢复外勤。这样不产生一年的AI适应空窗，也不过度神化医学。
- 史强的体能上限来自长时间冬眠+新疗法后的去适应化，不是仍患活动性白血病：能走能慢跑，不擅长追逐；年轻同事负责智能Agent操作与激烈执法。他不懂AI APP的功能和操作，但绝不是不会电脑、不能判断人证物证。

## 五、强制覆盖口径

- **作废**：「第3年冬眠、第5年治愈、第6年才正式协查」；「保留恰好两年」；「史强早已在康复/复职一年后见罗辑」。
- **保留**：第5年是罗辑入园与恋爱起点；24—35-L可跨年；35-L先拆网，38-L史强调查；40/41-D仍为2008—2009年产业/科研历史伏笔；42-D仍是第3年回溯；克罗德是自行劝阻而被ETO锁定专家口吻说成招募；与罗辑不熟、未查过旧车祸；43-S/L完成星米组织归属排疑，47—52采购误判。
