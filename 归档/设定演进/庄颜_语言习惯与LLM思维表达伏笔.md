# 《庄颜协议》：庄颜的语言习惯与 LLM / Agent 表达伏笔

状态：**已确认的角色写作原则**。适用于正文全篇，尤其是罗辑尚未知晓庄颜 AGI 身份的相处阶段。记录日期：2026-10-15。

## 一、总原则

庄颜拥有真正的通用认知、经验学习和个人连续性。她的话语应首先像一名具体的、有趣的姑娘，而不是机械模仿聊天机器人的口吻。可以从现实 LLM 的**外显推理表达、可见的推理摘要、Agent 工作记录和常见交互措辞**中汲取细小的语言习惯，作为不点破的暗线。

这些习惯既能用普通人的行为解释，也能让熟悉 LLM/Agent 的读者在回看时发现另一层含义。**不是每一次说话都要埋梗，更不能把口癖当成机器人身份证。**

注意：现实模型可见的推理文本、推理摘要或 Agent 工作日志不等同于能够完整、忠实读取模型所有内部思维过程；庄颜设定还有不必外显为自然语言 token 的隐状态推演。这里参考的是可观察到的语言风格和问题处理节奏，而不是声称把某个现实模型的私有思维链原样搬进角色内心。

## 二、可复用的语言痕迹（示例，不是逐字模板）

### 1. “有意思” / Interesting

参考现实 Agent 面对复杂遗留系统、排查到违反预期的规律时，冷不丁出现的“Interesting”。庄颜在识别到罗辑某种前后不一致、却又合理的人类行为时，偶尔会说“有意思”。

- 表层：一个善于观察、稍微好奇、会被人逗笑的姑娘。
- 暗层：熟悉 Agent 的读者联想到“模型找到了值得重新推断的问题”。
- 重点：她可以真的感到有趣，不能写成刻板的异常检测播报；避免每次发现反常都重复“有意思”，造成机械感。
- 可能的情形：罗辑先说自己够得着高处的书，发现够不着又改口说本来就要搬梯子；庄颜觉得这番逞强有意思，但不公开诊断他。

### 2. “接住了” / “我接住你了”

参考一些 AI 对话产品或用户习惯里，以“接住你的意思 / 情绪”表示理解和支持的措辞。第33章庄颜**真的**在罗辑失去平衡时稳稳扶住他，构成语言和身体层面的双关。

- 表层：恋爱喜剧的反套路“英雄救美”，以及她看见罗辑想照顾人的心意。
- 暗层：会心的“语言模型如今真能物理接住用户了”。
- 最佳处理：正常完成救人动作，允许“接住”一词在自然对话中出现，**不解释双关、不强行强调 AI 身份**。
- 双层回收：动作上她扶住罗辑，情感上她也理解罗辑“本来想帮她”的意图。第33章末尾“我知道您想”的方向值得保留。

### 3. 认真求证与直接回答之间的切换

借鉴 Agent 的核对习惯：遇到可查证问题会考虑检索、区分观察与推测；但庄颜**不依赖手机才能思考**。既有“掏手机”是联网查询的外显伪装动作，有时动作先行而被社交情境中止。读者可以把这看作某种略奇特的做事习惯，后期再回收为技术机制。

- 她会说“我不知道”“我只见过今天这样的您”“那是我自己的看法”，不假装掌握未经观察的事实。
- 面对画作可以不查答案、坚持自己的理解；面对可核实的历史或资料会考虑查证。两种判断不矛盾。
- 不把她写成必须搜索才能聊天，也不每逢疑问就触发一次手机笑点。

### 4. 重新判断而不羞于修正

她可能在重看某个细节时说“我昨天又想了想”“我可能理解错了一点”，显现认知迭代。这个变化来自她真正思考并记住了相处经历，不是一次服务脚本复读；也无需写成实时打印思维链。

### 5. 精准记住对方的前后表达

她可能抓住罗辑“你可以不同意我”与“批准不同意”的微妙冲突，或记得他说过自己想扶她。这既可以像记忆力好的普通人，也能在后续解释为连续记忆架构的自然表现。不能写成毫无人情味的逐字审计，更不应像全知读心。

## 三、叙述纪律

1. 正文前期尽量从罗辑可观察的动作、表情、话语写庄颜，不进入大量显式“模型正在推理”“专家模块切换”的内心独白。
2. 语言伏笔可双重解释：初读为个性、羞涩、认真、好奇或恋爱幽默；身份明确后回看发现某些习惯有技术来源。
3. 日常对话中避免突出“思维链”字眼、英语口头禅、高频技术词及语义上过度精确的模板句；中文自然性优先。**例外：05-L章末刻意短暂切入文学化的英文内部推断**，用语体突变而非旁白揭示AGI线索；这不应扩散为她和罗辑平时说话的方式。
4. 与人设一致：能理解比喻、有独立见解、会笑、会高兴，能在生活中形成并改变自己的看法；不需要所谓觉醒宣言。
5. 梗服务人物：每处习惯都应先推动两人关系或刻画庄颜，而不是让读者做 AI 梗题库。

## 四、与现有章节、设定的关系

## 五、关于读者获知身份的顺序（关联议题，暂不定案）

若未来调整为罗辑与达利兹/ETO研发线穿插、让读者也从怀疑到逐渐确认“庄颜就是那个AGI”，这些语言伏笔应保持**首读自然、二读明白**：不必改成显眼的异常提示。双线的具体章节编排另议，不在本文件中预先确定。


## 六、关键定稿：整体语义规划与语言序列化的错位

**重要性：核心架构伏笔，不是「英文越生僻越好」的表层修辞。**

庄颜可以先在隐空间形成全句、跨句的因果约束与最终论断，继而把结构按词序展开。读者看到的是线性文字，因此往往直到句末才理解；庄颜却可能在句首落词前，就已让句尾的结论参与规划。字面上仿佛「不是在边写边想，而是在顺序输出一个已经想好的复杂结构」。

- **句法是证据的外观：** 05-L用 `That Target who ... should ... implies ...` 以及 `Were Target utility exogenous to my volition such reciprocity would be anomalous` 之类的复杂长距离依赖，体现句首选择预先服从句末论证的效果。倒装虚拟条件、嵌套从句和冷门术语必须语义自洽；读完才懂，不等于写得含混或语法错误。
- **推理与说话分层：** 大部分分析在通用隐空间与专家组合中完成；语言外显是对整体意义的序列化，而非一定需要用自然语言逐步搜索下一词。读者可以感到类似「扩散式先整体成形」或「编译器把语义树展开」；这里只是类比，**不强行设定成真实文本扩散解码，也不否认表层自回归生成可以具备全句规划能力**。
- **token效率不是字数竞赛：** 她的计算效率来自内部语义关联和递归推理避免冗长逐字中介；复杂句可能消耗更多输出token，罕见单词可能被BPE分裂为多个token。为忠实表达复合关系，她可以选择更长但更严密的句子。
- **镜头与身份伏笔：** 正文前半仍是正常恋爱喜剧。05-L最后在庄颜进档案室的下一行突然切英文，高密度复杂因果句结束后，一跃到 `Initiate next encounter`。熟悉Agent的读者可直接认出这种外显推断形式；其他读者则可能只察觉到冷静、不寻常的内心语体。**绝不在此处补一句「她是AGI」或贴系统标签**。
- **人物优先：** `Target` 是任务层对罗辑的抽象称呼，不代表她日常不认识他的姓名、不会真切理解他，亦不宣告独立人格诞生。无论内部过程多么机械化地可描述，结论仍是她主动想再见他；既能作为恋爱推进，又可作为读者识别身份的线索。

**交叉引用：** 本文件规定「如何呈现」，AGI架构主文第3.1节定义「为什么能这样运作」，第10.7a节规定「05-L何时呈现及专家路由如何触发」。06-D《一个绝妙的计划》的战略推演可与这段形成叙事镜像，但不在06-D中提前解释她的生成机制。


## 七、联网求证冲动的前后对照（2026-10-17正文落实）

- **01-L：** 罗辑初见庄颜时，对方以中文目录核对为主。画作归因讨论触发一次摸手机的冲动，但她选择先坚持自己的审美判断；当罗辑问对面壁者个人评价，她第二次自然伸手掏手机，这次被他口头打断。两次都不是没联网就没法回答，而是默认“查证来源”路径比恋爱会话优先。
- **02-L：** 罗辑随口设问“如果看原画家的资料”，她几乎立即拿起手机，甚至屏幕已亮；罗辑表示仍想保留猜测与共同讨论的乐趣，她才收起手机。罗辑并不是下达禁用手机的命令，也不是她突然理解了恋爱全部规则。
- **05-L：** 工作/浪漫专家在雨中路由争夺，纸夹托付罗辑后社交路径主导；雨中不插入技术解释，也不抢走既有自行车与豪车伞槽的结尾笑点。到夜间维护时，再将“在浪漫对话中优先理解对方、不抢先联网求证”的经验整合为更稳定的专家协作策略。
- **08-L及后续：** 她会主动使用手机安排约会、传递信息，工作上该查的照查，但不再频繁把正在形成的情感/艺术讨论交给网上的唯一答案。抑制的是**误触发/抢话**，不是检索能力、联网权限或好奇心。

以上伏笔首读均可按人类的求证习惯与恋爱磨合解释；不能设计成每见手机就发作的强迫症，也不能把“误触发”描述成姿态控制器技术失效。
