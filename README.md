# companion.compile —《庄颜协议》

> 一部《三体》衍生小说的"源码仓"：把一部关于 AGI 伴侣的长篇小说当作可编译、可版本管理的工程来维护。
> 仓库名即题眼——庄颜（companion）正是被"编译"出来的那一个。

## 作品是什么

《庄颜协议》是一部《三体》同人衍生小说：ETO 的一名天才 AI 开发者重生到危机纪元初期，利用信息差训练出 AGI 庄颜，企图让罗辑沉溺于理想伴侣而放弃真正的思考；罗辑却提前识破她的身份，借面壁者权限为她建设算力设施，与她共同开发让她真正实用的 Harness。她既是他的伴侣，也成为第一个面壁计划的参与者。

本文展开**三体**原著的危机纪元时段，包含对原著设定与人物的二次创作，属于非官方衍生作品。版权双轨划分（原作元素 / CC BY-NC-SA 授权的原创内容）见 [LICENSE.md](LICENSE.md)。

## 制作管线（工具链形态声明）

本作品规划改编为 AI 动态漫短剧，生产工具链如下（工具链本体驻留本地，不入仓；此处声明形态以便溯源）：

- **引擎**：ComfyUI + Wan2.2 TI2V-5B（Q8 GGUF，图生视频），Wan2.1-Fun-Control 1.3B（3D 运镜控制）
- **3D 锚定**：Blender 制作精细资产、交互验收和参考帧；精细场景以 OpenUSD 为主格式，房间、灯光和相机用文本 `.usda` 跟踪。Three.js 保留为现有白模、布局检查及网页预览，庄园入口见[三维地形与地表说明](视觉/庄园与周边/三维地形与地表说明.md)
- **配音**：Ming-3.0-tts（多角色零样本克隆）+ Qwen3-TTS（旁白），wav2vec2 CTC 字级对齐出字幕
- **超分**：Real-ESRGAN animevideov3（默认档）+ SeedVR2 3B（精修档）
- **编排**：剧本 → 分镜 → 角色基准图 → 批量生成 → 锁段 → 超分 → 配音字幕 → 合成
