> **设定对齐基准**：一切设定以 `正文/`（重排新编）为准；正文口径的权威记录是
> `正文/README_重排新编与修订记录.md`（逐日修订史）。其「后续连续性约束」六条是所有设定文档的过滤器，
> 摘录如下：
>
> 1. L 线前期智能家居是普通消费设备，≠PDC 安防/保密/消防/医疗网络；新 38 章拆的是消费网络层。
> 2. 庄颜掏手机是行为伪装，本体完整本地运行并可独立联网。
> 3. 星米手机/排插可自然出现，与 38 章去智能化不矛盾。
> 4. 星米品牌是公开常识，但新 1—2 章不报具体应用名；36-D 人择揭名后才提高星米显名频率。
> 5. 主题是罗辑发现庄颜会表达异议；以"设备做过什么"而非"设备来自谁"为背景。
> 6. 未覆盖原正文与老章节序号；审校发现冲突时以新版时间轴为准修订。
