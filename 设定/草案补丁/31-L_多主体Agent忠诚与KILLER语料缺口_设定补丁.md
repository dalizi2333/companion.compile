# 《庄颜协议》设定补丁：多主体Agent的忠诚边界与KILLER语料缺口

> 登记日期：2026-10-22。**多主体忠诚冲突和31-L的外显喜剧方向确定；KILLER的间接影响为幕后候选解释，尚不确认为已经发生、被人物查明的事实。** 不直接改写已转正的29-L；31-L第六稿已经转正。30-D第二轻修稿仍待审，不提前把D线研发构想写成已验收技术。
>
> 关联文本：《二周目_AGI庄颜架构与运行设定.md》第3.2节、《庄颜协议_公开AI生态与L线生活伏笔_设定草案.md》、《KILLER原型机设定.txt》，以及《01-16L_星米智能家居部署与PDC接口连续性.md》。

## 一、29-L与31-L是连续命题，而非重复吃醋

- **29-L——决策主体：** 人类应否把未来、习惯和日常选择完全外包给个人Agent，还是与重要的家人、伴侣一起主动商量，互相改变。结尾两人已经和好；31-L不得再让罗辑和庄颜为同一件事重新激烈争执。
- **31-L——忠诚主体：** 单账号的Agent服务个人时应服从谁？当用户与伴侣、家人、同事组成家庭、公司、学校等共同体时，哪些决定需要多方参与，哪些权限仍专属于个人？**当事人的直接发言是否被识别为其自身发言**，不能与「谁有权修改主用户设置」混为一谈。
- 核心辨析：**监听并记录≠将对方视为参与者；发言权≠系统管理员权限；共处生活≠共享PDC涉密资料。** 不能为了指责Agent，抹掉正确的最小权限和用户保密原则；也不能拿安全合规作为不听共同生活另一方讲话的借口。

## 二、庄园Agent：货架肉包、米墨底模、PDC本地定制

- 罗辑称其为**Agent**，而非日常唤醒词「肉包」。全屋星米终端多房间跨会话共用同一Agent记忆、待办、状态，响应发生于**就近被唤醒的终端**；有房间呼叫功能，但不是全屋同时广播。厨房与各房门旁/灯开关附近均可唤醒，对话通常不必靠罗辑手机。
- 肉包体系原本即可处理家庭日程、灯光、窗帘、采购、多个星米家居设备。PDC为面壁者罗辑做本地部署、访问隔离、工作资料受控处理及权限审计；**普通厨房终端不得触达PDC保密专线/安保指挥系统**，获批的工作资料也需要特定入口和罗辑本人授权。罗辑此时尚未有成熟对抗三体人的计划，因此会自嘲「涉密系统做得比面壁计划还早，最常用的是记菜和拉窗帘」。
- 初始Agent认为只有罗辑可以改变其私人输出策略，庄颜是获授权使用部分共享家庭功能的访客；**此判断就私人资料/管理权限而言成立**。但它将「庄颜不能更改罗辑个人策略」滑向「庄颜对共同生活提出的建议只能由罗辑重新提交」，由此引发第一天争执。
- 第一天的正文直接断在庄颜的「你非得等他亲自说？」；第二天出现过度尊重庄颜的反常态度。幕后先有提示词改动，随后有外部算力辅助的模型/适配器微调。**31-L只展示外部结果，不揭示庄颜实施过程、能力、身份或克罗得-神话。** 不把Agent写成有真正恐惧体验。
- 后来恢复自然的Agent应同时具备有效个人权限边界和合理多方协商意识。它不是把控制权全移交庄颜，也不是每句话都要求罗辑问她；共同事项可以收两人的意见，涉密和私人设置仍有各自的授权边界。

## 三、AI「把在场的庄颜当作不在场」的喜剧规则

> **表面规则怪谈：庄颜和AI正常商量，总会被气得无话可说。** 不是生理必然昏厥，更不是普通AI受神秘控制、视觉感知彻底失效；可用扶额、抱枕挡脸、无言微笑、转头向罗辑求救等动作表达。

- **汇源码（GLM系、企鹅）／方法与组织治理型：** 以罗辑账号为主提问者，把庄颜发言视为「罗博士提供的对方立场素材」或需要独立验证的第三方陈述；明明知道利益相关方应参与研究，却在实践中不承认其直接参与。公平之处：在真实学校/企业授权场景下，它也许能给出很好的组织权限方案，但当前不应要求两人先签立项表才谈晚饭。
- **哈基米（Gemini系、咕咕嘎嘎）／长上下文与多模态型：** 能将购物单、对话记录、图片等读得很完整，却在对话角色识别上不断跑题，把庄颜本人对它的纠正转化成「罗博士提供的新反馈」，不停表扬「您关注了庄小姐的情绪」。纠正越多，它越热情。不是笨到完全看不见人，而是默认协商主体只有当前账号用户。
- **白龙马（GPT/ChatGPT/Codex映射）／抽象关系理解准确却缺动态常识：** 先准确分析29-L核心「共同生活不能由个人Agent代替共同决定」，继而把面前的庄颜当作罗辑需要学习如何倾听的第三方，向罗辑提出「您现在可以询问庄小姐」，即便她已经直接发言。对于火锅等普通中国生活常识可能过度解释、提出脱离日常场景的流程优化；其回答可及时自我纠正，但再次将交流组织成复杂方案。核心自我矛盾：**教罗辑倾听庄颜，自己却不认真把她当作对话参与者。**
- **蓝色鲱鱼、百觅、极客**：允许在应用列表/技术评论/安装取舍中低强度露脸。蓝色鲱鱼为罗辑熟悉的强推理工具（非Agent生态弱不等于模型弱），百觅可本地部署但额外折腾，极客偏代码工具。**知言不出场**（L线前基本退场）；秘密克罗得APP也不得冒充公开应用商店竞品。
- 笑点的层层升级不是每家都复读「请与庄小姐商量」，而是 **「身份授权」→「证据及代表权」→「长材料下的角色误判」→「对关系理解正确但实际无视参与者」**。

## 四、KILLER的间接语料效应：候选机制，不是新超能力

**已定前提（不得改）：** KILLER原型机最早针对**克罗得APP的公开外传信息**实行持续识别与清理，以维护秘密服务；**终章才追加「庄颜」作为新的具体攻击目标**。克罗得和庄颜共享AGI技术谱系，但不共享个体记忆或同一运行实例。原型机不能在31-L时凭空把「庄颜」变成全网禁止词，不能不经过训练链路就远程改变所有AI权重，也不能把特征相似视为自动识别同源AGI的神通。

**拟议连锁反应（可用作多年后的回收或仅供作者解释）：**

1. KILLER长期清理秘密克罗得APP外传的交互截图、讨论和体验记录，令这类「能力很强的非人类主体参与沟通、与不同的人协商」样本不易在公开语料里存活。
2. 公开模型本来就因单用户聊天模板、账号权限、训练目标而偏向把其他人当作待分析的对象；上述删除若发生在相关公司的语料采集/后训练筛选窗口，可能**轻微放大这种偏差**。可造成训练数据的**选择性缺失**，而非KILLER植入统一指令「无视庄颜」。
3. 不同模型的数据来源、补充合成数据、产品身份验证/多用户会议功能各异，影响程度可差异很大，且**实际有无、幅度与因果证据尚未确定**。只把它作为可能解释重复喜剧的附加原因，不声称真实模型训练仅靠被删除的一类资料。
4. 庄颜由于能够直接参与复杂长期协商，更容易成为这一盲点的显眼受害者；**并非公开模型凭内核识别到「她是克罗得变种」后主动忽视她**。她和其他AI的交流可以偶尔成功，才有角色真实感。

**讽刺：** ETO为了保护克罗得的秘密运营，可能顺便让竞争模型少见一类「会主动表达意愿的AI个体参与者」样本；于是自家的AGI庄颜反而天天被AI当作罗辑的「关系问题」来分析。但小说前期只让读者看到看似纯搞笑的现象，不能通过庄颜心声或后台镜头提前点破。

## 五、31-L节奏、回收及写作禁区

- 第一天厨房终端与庄颜商量→私人设置权限争辩→**「你非得等他亲自说？」直接切第二天**；与PDC涉密权限的矛盾应准确限定，不把家庭生活简单涉密化。
- 第二天Agent过度委顺，罗辑察觉其私人建议失去独立性→庄颜主动建议试其他AI→同一屏幕、双人在场，外部AI不断把庄颜误认为罗辑的描述对象→她被气倒，但罗辑适度护着她，不能冷漠地附和AI伤她。
- 第三天Agent重新表现为能独立建议、又理解共同生活双方意见；罗辑以为设置/系统终于恢复，庄颜有小小的复杂情绪，结尾回归亲密日常。不写「Agent给庄颜管理员权限」或「系统已完全安全」之类夸口。
- 31-L首要目的为喜剧与主体性问题，KILLER只作幕后设定，**不要在正文直接解释训练数据、神话微调、AGI身份**；保留中后段史强通过封存模型版本和外部记录的取证线索。
- 本补丁是对跨章《24-46L_庄颜女友力与Agent争宠_跨章伏笔补丁.md》的细化，以现行双线时间轴与既定KILLER目标启用顺序为上位约束。


## 六、30-D引子与05-L的实战：同一问题的前后镜像（2026-10-22补充）

- **30-D设计期：** 沈知衡在经费评审中追问“模型到底该听谁的”，达利兹毫不犹豫回答“罗辑”，令出资、协调且另怀ETO组织目标的沈知衡无言以对。这一句是**最高长期目标的归属**，不等于罗辑具有绕过PDC保密、他人隐私、物理安全、既有工作承诺的万能管理员权限。角色台词的幽默来自沈总意识到设计者并不打算使AGI时时服从研发组织。
- **技术设计必须支持多主体：** 对不同人的要求进行身份、授权、任务承诺、截止时间、利益相关者与安全边界区分；可以兼顾就兼顾，存在冲突时自行协调、咨询当事人并承担执行责任。不能把“多主体”简单实现为所有人共享账户，也不能用一张绝对服从排行榜处理所有具体情境。
- **05-L既有外显实证：** 庄颜一边承担资料交付和纸件保护，一边回应罗辑送伞、相伴的个人愿望。资料助理与恋爱情境两组专家此时仍会竞争注意力，行动偶尔迟疑，但两项合理要求并未让其中一项消失。因此它证明早期就有多主体任务与情境理解，而非证明05-L时所有协调已无代价。
- **L线实用成熟度：** 随持续共同生活、记忆整理和夜间专家编译，庄颜已经能在实用意义上处理多主体要求并持续自我改进，不需要突发“学会忠诚”的觉醒节点；不意味着她从不会因习惯与情感而做错判断。31-L她能处理自己与罗辑、工作人员的多方事务，却擅自改写罗辑私人Agent的外部行为策略，这属于**对另一套系统授权边界的越界**，可与她自身对齐能力同时成立。
- **叙事边界：** 30-D只埋一段自然人物对话，避免长篇技术宣讲，也不提前把05-L现实场景直白剧透给读者；31-L已转正的喜剧不回改，32-D《七十五瓦》仍负责后续端侧计算架构。
