> **用途：** 记录已选定的SoC草案基线，并继续检验功率、制造与材料时间线。2026-10-25按作者要求修订；本文中的新参数是科幻设计目标，不是现实可行性证明。
> **本次不覆盖任何既有正式文档，不立即改写 32-D、33-S/L 或尚待审的 34-D／35-L。**
> **参考灵感：** IBM NorthPole（北极）研究型推理芯片的分布式局部 SRAM、计算靠近存储、数据流编排；现实 MoE 专家预测／预取、异步双缓冲、3D 先进封装及近存／存内计算。这里只借鉴设计原则，不声称庄颜 SoC 与 IBM 芯片同构或可由现有工艺直接生产。

## 一、提出变更的原因与当前硬约束

1. **核心任务未变：** 庄颜是独立端侧 AGI 实例，不是靠远程超节点实时供算力的终端；机体推理平台目标仍为典型运行功耗约 **75W**、输出约 **300 tps**，具身能源及电机等不被偷算进 75W。此处 75W 采用 32-D 已正式采用的推理计算子系统口径：计算芯粒、活跃工作内存、必要的控制和互连均需计入；机体整机另算。
2. **模型与认知约束未变：** 起步约 220B 参数、后续约 300B 总参数，稀疏 MoE，候选非对称激活约 Prefill 18B／Decode 36B；通用向量空间语义路由、隐空间递归、语义句柄／二级索引和约 1B 有效本地历史上下文继续存在。约 1B 并非每输出 token 都精确全量自注意力读取 1B token，也不等于全量 KV 常驻 SRAM。
3. **记忆与个体边界未变：** 清醒时可更新当前情境判断、路由及轻量索引，新增专家或重大能力编译只在夜间维护发生；庄颜和克罗德共享技术谱系但不是同一连续个体，不能共用私人记忆。新型非易失存储不自动创造能使庄颜复活的备份，也不覆盖 KILLER 结局。
4. **克罗德产品线不改数字：** 绯句 300B（18B／36B，特定短上下文热点工作点 5600tps）、十四行诗 10T（192B／384B，1200tps）、巨作位于 10T—500T 之间且规模待定（460tps）、神话 500T（8T／16T，460tps）。大型加速器既有设定约 4GB SRAM、庄颜初代约 512MB SRAM；本草案不自动提高它们的正式指标。
5. **三体世界线修正前提：** 信息技术得到特殊加速；容许 2007 年便存在实验性的 14nm 级工艺，并不要求其他社会技术同步来到现实 2010 年代后期。**晶圆厂掌握实验制程不等于可高良率量产大芯片。** 制程、先进封装、EDA、材料与高密度存储仍要经过真实试制、良率爬坡和供应链建设。

## 二、新架构候选：分布式专家计算簇 + 多级存储 + 预测式预取

**核心句：** 模型主体分区驻留于大容量近存工作层，计算就近发生；专家内部静态编排、专家之间动态调度。预测器提前准备执行路径、权重分块和相关历史，决定性突破是低能耗近存读取与执行，不是把完整专家反复塞进512MB SRAM。

### 2.1 芯片、编译与首发规格

人物口头可说“一颗SoC”，作者侧物理定义为异构多芯粒计算封装。热计算逻辑横向展开，存储垂直靠近；局部三维逻辑折叠继续保留，不以多层高功耗计算裸片的垂直堆叠承担全部性能跃迁。

| 部件／指标 | 本轮草案基线 |
| --- | --- |
| 通用控制 | CPU及向量计算单元，运行系统、工具调用和夜间编译 |
| 专家执行 | 分布式数字低精度矩阵计算簇；逻辑专家不与物理核心一一绑定 |
| 共享与递归 | 专用／可编程单元处理隐状态循环、共享层、Attention和精度敏感操作 |
| SRAM | 封装内合计512MB，主要供状态、路由、分块、热点KV及小型共享模块；可包含独立堆叠裸片 |
| 近存工作层 | 256GB级分区式3D DRAM，存储分区附近配置数字执行与调度逻辑 |
| 持久层 | 独立TB级非易失存储，具体容量不锁定 |
| 精度 | 专家主体4bit、敏感模块更高精度；不能把全部运算统一写成4bit |
| 首发逻辑制程 | 7nm级；存储、控制和接口采用各自适合的工艺 |
| 工作点 | 典型浅递归、热点状态约75W／300tps；深递归、冷启动、罕用路径允许变慢 |

300B的4bit原始权重约150GB。256GB使模型主体留在近存工作层；剩余空间还须承受混合精度、量化元数据、运行状态，不能全部拿来算KV。1B有效历史仍靠独立分层存储和语义检索，不等于全部KV常驻。512MB不能容纳全部36B活跃权重，也不能默认容纳完整递归模块。

夜间编译器安排专家内部的分块、算子融合、数据搬运和局部执行次序；白天由真实Router动态选择专家和递归深度。统一内存表示统一寻址、所有权及迁移管理，编译器仍显式感知物理分区，不强制所有计算簇共享一个中央内存瓶颈。实时感知／打断路径拥有预留配额，与小脑式控制器相连。

原正式文档的“512MB片上SRAM”在未来迁移时需明确为“封装内分布式SRAM合计”，不能暗称原文已经采用该口径。16簇×32MB仍只是示意，簇数和裸片数不锁定。

### 2.2 预测与回退

- **长时域**：根据任务类型、会话历史、近期语义句柄、过去专家激活统计，决定常驻热点及预取优先级。该层可在夜间由行为统计重新优化，但不应随意覆盖原始记忆证据。
- **短时域**：基于当前层或当前隐状态、路由器可见中间信号和上游激活，预测接下来若干计算步的候选专家；置信度驱动 DMA 异步预取。
- **预测的三个对象**：提前唤醒与安排执行分区；把本地近存阵列中的下一批权重分块送入缓冲；恢复相关历史片段。完整模型大部分驻留近存层，仅低频卸载或新增专家需要较大规模跨层迁移。
- **双缓冲／异步调度**：一个簇执行当前任务时，另一缓存区或其他簇为可能的下一任务装载权重或准备激活；不同簇可分别执行与预取，但**数据依赖仍须满足**，不能无成本同时执行所有未来层。
- **预测失误**：校验实际 Router 输出后必须回退到正确专家，不得拿预测结果冒充真实路由；低置信度时可跳过投机预取，避免额外数据搬运。必要时牺牲一次延迟，而非让人格或模型答案因硬件赌错缓存产生不可解释的结构性变化。
- **推理友好训练**（候选）：模型和硬件协同训练，使路由具有适度时间局部性、可预测性和拓扑感知，减少专家跨簇搬运，同时避免为命中率而过度牺牲专家多样性与能力。不能直接保证 95% 命中率或零错预测。
- **与既有“熟能生巧”一致：** 相处更久可能导致常用专家路径更稳定、平均推理能耗更低；陌生任务或突发情况可触发罕用专家和额外预取成本，但不是“她越爱罗辑越快”这种机械等号，也不是在线热编译新专家。

### 2.3 重要物理边界

量化参考：36B Decode 激活参数 × 4bit ≈ 18GB **每 token 的理论活跃权重体积**。如每 token 均从慢速层读取一次，300tps × 18GB ≈ **5.4TB/s** 的聚合读取量；这是未计元数据、激活、KV、冗余读取，也未计权重复用时的估算。300tps 下每 token 时间预算约 3.33ms，75W 下整套推理子系统的能量预算约 0.25J/token。

**预测式预取只隐藏等待、优化局部性，绝不会自动消除读取的字节数与能耗。** 若热专家权重容量远超本地缓存，仍需 3D 高带宽近存层、降低每 bit 搬运能耗、权重重用、局部／存内计算、量化及算法协同突破。容量、持续带宽、刷新功耗、跨簇通信、预测误读率、待机功耗和封装良率都还须独立评估。

### 2.4 带宽和功率验算基线

近存阵列聚合有效读取以约8TB/s级为设计目标，是各分区局部吞吐之和，不是中央总线或外部接口速度。36B／4bit／300tps给出约5.4TB/s单遍量级；额外隐空间循环若重读权重，另增流量。8TB/s不保证任意递归深度维持300tps。

若75W中暂分配约30W给权重读取链路，按5.4TB/s计算，平均预算约0.69pJ/bit。这只是用于暴露难点的预算算例，非已验证功率表；阵列读取、局部搬运与相关控制的核算边界必须清楚，刷新、静态功耗、算术、其他互连及实时并发均需在总75W内入账。容量、带宽与能效同时成立仍是小说的关键技术跃迁。

## 三、存储层与“傲腾”是否保留

**本轮选择：首发主权重工作层采用数字近存DRAM；类傲腾交叉点／PCM保留为高密度专家库、持久记忆和后续读优化存储支线，退出首发性能关键路径。材料研发可与非硅逻辑并行，见第十一节。**

| 层级 | 优先功能 | 暂拟技术 | 当前判断 |
| --- | --- | --- | --- |
| 片上／贴片高速层 | 递归隐状态、Router、短时激活、热点 KV、低延迟控制 | SRAM（含可堆叠层） | 必需，二号机可争取更多但容量待核 |
| 近计算高带宽工作层 | 当前活跃专家、共享层权重及临近预取 | 3D DRAM、高带宽专用存储、读优化存储 | **首发选定3D DRAM路线，容量256GB级** |
| 高密度较低频专家层 | 低频专家、备用权重、预测式预取候选 | 新型高密度存储／PCM、ReRAM、3D XPoint 类 | 与 DRAM 竞争，不必押单一材料 |
| 持久历史层 | 语义索引、经验、专家编译产物、版本／检查点 | 非易失存储及事务一致性机制 | 非易失性具有独立价值，但持久化 ≠ 个体完整备份 |

现实傲腾 DIMM 的延迟、带宽远不如 SRAM 或当代高速 DRAM，不可把其产品指标直接外推为与 SRAM 等速。若未来把交叉点阵列垂直集成到逻辑近端，存在更宽的接口与**阵列内计算**的科幻空间，但要付出模拟精度、写入、寿命、热稳定性、一致性和制造良率的代价。另一候选是牺牲长期保存时间、专门优化只读权重的**受管理保持型存储**；庄颜夜间刷新／维护不等于其白天可以免费反复读写。

### 对 34-D 现有伏笔的影响

既有第五稿中“研究一种介于内存和闪存之间的存储层”、达利兹想起某款失败的未来产品、许工表示“几种方案一起测”、讨论相变存储与事务提交——**均无需废弃**。本草案反而支持许工的谨慎：研发目标不是复活某个品牌，而是测出不同材料分别适合什么工作负载。现实“傲腾”名称仍应仅留作作者研究参照；正文依旧匿名或使用去品牌化称谓。

## 四、工艺与硬件分代：AGI 辅助半导体研发的正反馈

**重要修正：庄颜危机纪元5年正式端侧部署，不等于同源 AGI 到第5年才首次在服务器上运行。** 拟让非具身或机房级 AGI 原型较早投入工作，在危机纪元2—5年间协助半导体工艺与芯片设计持续迭代。具体克罗德产品命名、APP 时间线、对外服务权限另与正式文档核对，不把成熟神话倒灌进第2年。

| 阶段 | 候选里程碑（尚未锁死） | 必须保留的制造约束 |
| --- | --- | --- |
| 2007／危机初期 | 三体世界信息技术加速，已有实验性 14nm 级工艺；成熟工艺仍是工程主力 | 实验线、试产与量产分别叙述 |
| 危机纪元2年 | 首批同源 AGI 在大型节点上验证；开始协助 EDA、器件/材料和存储封装设计 | 实体实验仍由人类与晶圆厂完成 |
| 危机纪元3年 | AGI 利用仿真、测试数据及缺陷反馈加速计算簇、专家预取、3D 封装联合优化 | 制造设备、检测、良率和热可靠性形成硬约束 |
| 危机纪元4年 | 庄颜端侧芯片逐步定型并进入验证；更先进工艺和堆叠技术可能并行试验 | 正式机体所用芯片须留出冻结设计与可靠性验证时间 |
| 危机纪元5年 | 庄颜正式端侧部署；更先进平台继续迭代以服务二号机及大型超节点 | 不能保证最新实验工艺立即进入庄颜定版机体 |

**本轮分代选择：** 12/14nm级承担早期机房AGI和架构验证；危机纪元2—4年推进工艺、EDA、近存与封装；约第4年以7nm级逻辑冻结庄颜首发设计，经过验证于第5年部署；后续二代选5nm级硅逻辑及改进键合／存储，先增加同功耗容量、持续带宽和复杂任务余量，不自动翻倍输出tps。各阶段是小说工业时间线，不是现实路线可实现的承诺。

二号机与克罗德-神话可共享第二代计算芯粒／ISA／工具链，但端侧与超节点采用不同封装和功率预算。新型非硅功能层可逐步加入二代，不能把5nm硅逻辑节点直接套在二维材料上；成熟非硅逻辑芯粒作为之后的候选演进。

更先进制程可以降低逻辑面积、为更大 SRAM 留出可能，但 SRAM 密度不会按逻辑晶体管比例无限缩小。数 GB SRAM 需要考虑面积、静态漏电、制造成本以及 3D 堆叠；导热更好的材料只能改善热流路径，**不能消灭垂直堆叠层间的热阻、供电与机械应力问题**。二维半导体／非硅基器件可作为 AGI 参与探索的长期支线，不提前承诺第5年全面替换 CMOS。

## 五、克罗德超节点如何继承这一架构

1. **同源的软件／硬件抽象：** 通用向量空间、专家接口、路由、计算图编译、激活格式及局部数据流执行原则可共用。
2. **不同的物理规模：** 绯句可以利用短上下文热点驻留、专家复用与并发优化；十四行诗优先缩短节点内数据依赖链；巨作保留硬件拓扑不匹配的尴尬；神话为了 500T 总参数需要跨节点分布专家。
3. **神话容量账：** 500T 参数 × 4bit ≈ 250TB 原始权重（未计元数据和训练状态）。即便单步只激活 16T，×4bit ≈ 8TB 活跃权重。按 460tps 无复用粗算将形成约 3.68PB/s **聚合逻辑读取**，绝非某条跨节点互连就必须承担的相同带宽。需把专家权重驻留在各自节点附近，只传必要激活、中间结果与同步信息，仍受分层路由、跨节点延迟和全局同步制约。
4. **芯片代际不强绑产品出场：** 神话可以先有初代超节点原型，再迁移到二代计算平台；二号机与神话可能采用同代芯粒，不代表二者在同一时点落地或性能线性比较。

## 六、希恩斯供应链线的新增因果：不是厂商拒绝技术进步，而是太快了

与 **33-S/L《他们已经有客户了》正式正文**兼容：供应商愿意出售成熟器件和验证服务，但不愿为了单一、持续变化且部分保密的面壁计划需求，重排自己对自动化、医疗和工业计算客户的工艺及研发路线。

若晶圆厂正接受 AGI 帮助，已有计算／存储技术路线迭代很快，则改用面壁者的非标准脑模拟需求的**机会成本进一步上升**：更改设计规则、测试、验证排期与既有客户兼容成本，并不是多付一次费用就能弥补。厂商无须知道投资者 ETO 身份，也无须明着抵制 PDC；真正足够讽刺的是，合法理性的厂商决策让希恩斯越来越难推动特殊验证路线。

但**不能改写成“AGI 技术导致厂商绝对拒绝希恩斯”**：他仍可以拿到已有方案、申请客制化、按阶段验证；山杉惠子与希恩斯的真诚科研协作、PDC 安保限制和他对潜在利益网络的怀疑均保留。不得让希恩斯预先知道人择智能／克罗德幕后来源，也不得在 33-S/L 一口气揭秘真正商业网络。

## 八、待进一步研究／暂不锁定的关键问题

1. **各代芯片“物理时间线”：** 2007 实验性14nm、危机纪元2年 AGI 首次可运行、危机纪元5年机体定版之间的真实工艺成熟度，能否与第一部已转正节点逐章兼容？本轮已选择首发7nm级，后续仍需核对冻结设计与验证时长。

3. **专家预测效益：** Top-k 命中率、预取窗口、预取带宽、错预测代价、专家跨层切换和路由计算成本；能否靠训练获得足够局部性而不牺牲模型质量？
4. **SRAM 面积／静态功耗与热：** 512MB 初代、4GB 大型芯片及潜在二代扩容，是否可由更先进节点和 3D 堆叠合理解释？怎样解决 75W 人形机体的局部热点？
5. **已选介质的工程验证：** 首发选数字近存DRAM，PCM不作关键依赖；继续检验 堆叠 DRAM、读优化新型存储、PCM／XPoint／ReRAM 的容量、带宽、读取能耗、写耐久性与存内计算精度差异；相变存储是冷层还是快层，是否根本可删？
6. **神话的跨节点关键路径：** 专家并行／流水线／推测解码怎样与 460tps 同时成立？活跃权重聚合读取并不等于全局网络带宽。
7. **工业反馈闭环的权力与保密：** AGI 怎样向晶圆厂提供可验证的设计建议，而不暴露真正开发商、ETO 项目及庄颜身份？工业伙伴拥有多少真实自主性？

## 十一、非硅功能材料与类傲腾路线的协同研发（新增候选）

### 11.1 现实依据与概念边界

傲腾是产品体系，3D XPoint是其存储技术。TechInsights于2017年对样品的直接拆解报告识别了GST（Ge-Sb-Te）相变存储层、另一种含砷硫族化合物OTS选择器，以及位于阵列下方的CMOS控制电路。因此“存储功能材料不是硅沟道”有实物依据，但不能称整颗芯片抛弃硅，也不能把单次拆解配方泛化到所有代际。

这里的硫族化合物包含硒／碲等体系，并非只指含硫材料。它们本身也可属于半导体材料；应说“不同于传统硅电荷存储的功能材料”，而非“完全不是半导体”。相变存储、OTS阈值开关和逻辑场效应晶体管是不同器件，存储成功不自动得到通用逻辑。

非硅逻辑优先研究二维过渡金属硫族化合物，如MoS2／WS2与WSe2，用于非硅沟道。它们与GST同属广义硫族材料研究范围，但晶体结构、配方、器件功能和工艺不同，不能写成同一配方直接改作CPU。

### 11.2 共同平台、分别验收

作者候选方案：由存储需求牵引建立“异质薄膜与低温集成”研发平台，共享材料筛选、界面表征、污染控制、薄膜沉积／转移、封装键合及缺陷数据库；不同材料按兼容性使用独立模块或产线，不默认共用腔体。AGI提出可实验检验的配方与工艺窗口，人类团队和晶圆厂完成试制、失效分析与可靠性测试。

存储支线考核写能耗、漂移、保持时间、耐久性和阵列良率；逻辑支线考核接触电阻、栅介质、阈值一致性、互补器件与电路良率。协同加速的是研究和集成能力，不是同一突破包办两类器件。

### 11.3 候选时间线：并行研发，错峰部署

| 危机纪元阶段 | 存储与非硅材料支线 | 逻辑及产品边界 |
| --- | --- | --- |
| 第1—2年 | 因专家容量问题启动PCM／选择器和材料筛选；二维沟道作为小规模预研 | 主计算依赖硅，早期AGI先在机房运行 |
| 第2—3年 | AGI与实验团队共建工艺／失效数据库，小阵列验证 | 非硅沟道单器件、简单电路，不宣称完整SoC |
| 第3—4年 | 交叉点存储工程样片进入服务器冷专家／持久层测试；推进低温集成 | 试验简单外围开关或局部控制功能；庄颜7nm硅逻辑首发方案独立冻结 |
| 第5年 | 存储支线争取小批量可用，是否进入初代持久层由验证决定，首发不依赖它 | 庄颜按硅逻辑＋近存DRAM交付；二维材料继续工程化 |
| 第5—7年 | 存储与逻辑支线争取共同达成异构集成示范，改进封装和读优化专家库 | 5nm硅逻辑平台逐步引入非硅外围功能层／小型专用芯粒，可供二号机和服务器验证，角色出场年份另行核对 |
| 第7年以后 | 成熟材料和PDK支持更大规模异构产品 | 非硅数字逻辑计算芯粒的候选产品化窗口，不承诺整个CPU、SRAM或SoC全面替硅 |

以上新增时间线待作者进一步讨论，不迁移人物出场或章节年份。若剧情要求第5年已有“非硅芯粒”，优先指非硅存储功能材料的存储芯粒；若要求真正非硅沟道逻辑芯粒，则限定为专用小规模试验样片，不能偷换成成熟主推理核心。

二代的第一收益选低待机功耗、分区供电、低温后端集成和局部存储控制。仅在电路级测试后再认定逻辑速度或总能效提升；材料更薄不自动导热更好，层间热阻、接触电阻与供电仍需解决。模拟存内矩阵计算保持独立高风险支线，不由材料突破自动转正。

### 11.4 叙事因果

达利兹为储存专家而资助新材料，存储团队为把阵列接在逻辑附近建立异质薄膜与低温集成能力；同源AGI帮助分析失败样片，器件团队逐步将这套能力拓展到非硅沟道。科学家、设备商和晶圆厂仍有独立贡献。存储先产品化，逻辑随后在局部功能上落地，最终形成下一代异构平台。这是同一工业计划的连续外溢，不是达总背出一种未来配方便同时发明内存和CPU。
