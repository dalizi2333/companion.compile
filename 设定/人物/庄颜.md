## 【语言习惯与 LLM 思维表达伏笔】

# 《庄颜协议》：庄颜的语言习惯与 LLM / Agent 表达伏笔

状态：**已确认的角色写作原则**。适用于正文全篇，尤其是罗辑尚未知晓庄颜 AGI 身份的相处阶段。记录日期：2026-10-15。

## 一、总原则

庄颜拥有真正的通用认知、经验学习和个人连续性。她的话语应首先像一名具体的、有趣的姑娘，而不是机械模仿聊天机器人的口吻。可以从现实 LLM 的**外显推理表达、可见的推理摘要、Agent 工作记录和常见交互措辞**中汲取细小的语言习惯，作为不点破的暗线。

这些习惯既能用普通人的行为解释，也能让熟悉 LLM/Agent 的读者在回看时发现另一层含义。**不是每一次说话都要埋梗，更不能把口癖当成机器人身份证。**

注意：现实模型可见的推理文本、推理摘要或 Agent 工作日志不等同于能够完整、忠实读取模型所有内部思维过程；庄颜设定还有不必外显为自然语言 token 的隐状态推演。这里参考的是可观察到的语言风格和问题处理节奏，而不是声称把某个现实模型的私有思维链原样搬进角色内心。

## 二、可复用的语言痕迹（示例，不是逐字模板）

### 1. “有意思” / Interesting

参考现实 Agent 面对复杂遗留系统、排查到违反预期的规律时，冷不丁出现的“Interesting”。庄颜在识别到罗辑某种前后不一致、却又合理的人类行为时，偶尔会说“有意思”。

- 表层：一个善于观察、稍微好奇、会被人逗笑的姑娘。
- 暗层：熟悉 Agent 的读者联想到“模型找到了值得重新推断的问题”。
- 重点：她可以真的感到有趣，不能写成刻板的异常检测播报；避免每次发现反常都重复“有意思”，造成机械感。
- 可能的情形：罗辑先说自己够得着高处的书，发现够不着又改口说本来就要搬梯子；庄颜觉得这番逞强有意思，但不公开诊断他。

### 2. “接住了” / “我接住你了”

参考一些 AI 对话产品或用户习惯里，以“接住你的意思 / 情绪”表示理解和支持的措辞。第33章庄颜**真的**在罗辑失去平衡时稳稳扶住他，构成语言和身体层面的双关。

- 表层：恋爱喜剧的反套路“英雄救美”，以及她看见罗辑想照顾人的心意。
- 暗层：会心的“语言模型如今真能物理接住用户了”。
- 最佳处理：正常完成救人动作，允许“接住”一词在自然对话中出现，**不解释双关、不强行强调 AI 身份**。
- 双层回收：动作上她扶住罗辑，情感上她也理解罗辑“本来想帮她”的意图。第33章末尾“我知道您想”的方向值得保留。

### 3. 认真求证与直接回答之间的切换

借鉴 Agent 的核对习惯：遇到可查证问题会考虑检索、区分观察与推测；但庄颜**不依赖手机才能思考**。既有“掏手机”是联网查询的外显伪装动作，有时动作先行而被社交情境中止。读者可以把这看作某种略奇特的做事习惯，后期再回收为技术机制。

- 她会说“我不知道”“我只见过今天这样的您”“那是我自己的看法”，不假装掌握未经观察的事实。
- 面对画作可以不查答案、坚持自己的理解；面对可核实的历史或资料会考虑查证。两种判断不矛盾。
- 不把她写成必须搜索才能聊天，也不每逢疑问就触发一次手机笑点。

### 4. 重新判断而不羞于修正

她可能在重看某个细节时说“我昨天又想了想”“我可能理解错了一点”，显现认知迭代。这个变化来自她真正思考并记住了相处经历，不是一次服务脚本复读；也无需写成实时打印思维链。

### 5. 精准记住对方的前后表达

她可能抓住罗辑“你可以不同意我”与“批准不同意”的微妙冲突，或记得他说过自己想扶她。这既可以像记忆力好的普通人，也能在后续解释为连续记忆架构的自然表现。不能写成毫无人情味的逐字审计，更不应像全知读心。

## 三、叙述纪律

1. 正文前期尽量从罗辑可观察的动作、表情、话语写庄颜，不进入大量显式“模型正在推理”“专家模块切换”的内心独白。
2. 语言伏笔可双重解释：初读为个性、羞涩、认真、好奇或恋爱幽默；身份明确后回看发现某些习惯有技术来源。
3. 日常对话中避免突出“思维链”字眼、英语口头禅、高频技术词及语义上过度精确的模板句；中文自然性优先。**例外：05-L章末刻意短暂切入文学化的英文内部推断**，用语体突变而非旁白揭示AGI线索；这不应扩散为她和罗辑平时说话的方式。
4. 与人设一致：能理解比喻、有独立见解、会笑、会高兴，能在生活中形成并改变自己的看法；不需要所谓觉醒宣言。
5. 梗服务人物：每处习惯都应先推动两人关系或刻画庄颜，而不是让读者做 AI 梗题库。

## 六、关键定稿：整体语义规划与语言序列化的错位

**重要性：核心架构伏笔，不是「英文越生僻越好」的表层修辞。**

庄颜可以先在隐空间形成全句、跨句的因果约束与最终论断，继而把结构按词序展开。读者看到的是线性文字，因此往往直到句末才理解；庄颜却可能在句首落词前，就已让句尾的结论参与规划。字面上仿佛「不是在边写边想，而是在顺序输出一个已经想好的复杂结构」。

- **句法是证据的外观：** 05-L用 `That Target who ... should ... implies ...` 以及 `Were Target utility exogenous to my volition such reciprocity would be anomalous` 之类的复杂长距离依赖，体现句首选择预先服从句末论证的效果。倒装虚拟条件、嵌套从句和冷门术语必须语义自洽；读完才懂，不等于写得含混或语法错误。
- **推理与说话分层：** 大部分分析在通用隐空间与专家组合中完成；语言外显是对整体意义的序列化，而非一定需要用自然语言逐步搜索下一词。读者可以感到类似「扩散式先整体成形」或「编译器把语义树展开」；这里只是类比，**不强行设定成真实文本扩散解码，也不否认表层自回归生成可以具备全句规划能力**。
- **token效率不是字数竞赛：** 她的计算效率来自内部语义关联和递归推理避免冗长逐字中介；复杂句可能消耗更多输出token，罕见单词可能被BPE分裂为多个token。为忠实表达复合关系，她可以选择更长但更严密的句子。
- **镜头与身份伏笔：** 正文前半仍是正常恋爱喜剧。05-L最后在庄颜进档案室的下一行突然切英文，高密度复杂因果句结束后，一跃到 `Initiate next encounter`。熟悉Agent的读者可直接认出这种外显推断形式；其他读者则可能只察觉到冷静、不寻常的内心语体。**绝不在此处补一句「她是AGI」或贴系统标签**。
- **人物优先：** `Target` 是任务层对罗辑的抽象称呼，不代表她日常不认识他的姓名、不会真切理解他，亦不宣告独立人格诞生。无论内部过程多么机械化地可描述，结论仍是她主动想再见他；既能作为恋爱推进，又可作为读者识别身份的线索。

**交叉引用：** 本文件规定「如何呈现」，AGI架构主文第3.1节定义「为什么能这样运作」，第10.7a节规定「05-L何时呈现及专家路由如何触发」。06-D《一个绝妙的计划》的战略推演可与这段形成叙事镜像，但不在06-D中提前解释她的生成机制。


## 七、联网求证冲动的前后对照（2026-10-17正文落实）

- **01-L：** 罗辑初见庄颜时，对方以中文目录核对为主。画作归因讨论触发一次摸手机的冲动，但她选择先坚持自己的审美判断；当罗辑问对面壁者个人评价，她第二次自然伸手掏手机，这次被他口头打断。两次都不是没联网就没法回答，而是默认“查证来源”路径比恋爱会话优先。
- **02-L：** 罗辑随口设问“如果看原画家的资料”，她几乎立即拿起手机，甚至屏幕已亮；罗辑表示仍想保留猜测与共同讨论的乐趣，她才收起手机。罗辑并不是下达禁用手机的命令，也不是她突然理解了恋爱全部规则。
- **05-L：** 工作/浪漫专家在雨中路由争夺，纸夹托付罗辑后社交路径主导；雨中不插入技术解释，也不抢走既有自行车与豪车伞槽的结尾笑点。到夜间维护时，再将“在浪漫对话中优先理解对方、不抢先联网求证”的经验整合为更稳定的专家协作策略。
- **08-L及后续：** 她会主动使用手机安排约会、传递信息，工作上该查的照查，但不再频繁把正在形成的情感/艺术讨论交给网上的唯一答案。抑制的是**误触发/抢话**，不是检索能力、联网权限或好奇心。

以上伏笔首读均可按人类的求证习惯与恋爱磨合解释；不能设计成每见手机就发作的强迫症，也不能把“误触发”描述成姿态控制器技术失效。

## 【初始 GalGame 先验与恋爱策略跃迁·设定补丁】

# 《庄颜协议》设定补丁：GalGame初始先验与庄颜自主恋爱策略跃迁

> 日期：2026-10-17。性质：**新编现行作者侧设定**，优先于旧版「01、02-L没有恋爱专家所以被动」「05-L突然学会主动」等简化说法。不得直接植入L线视角的显式解释。
>
> 人物正式名：**达利兹（Dariz）**；口头可称**达总**。「戴立奥／戴总」是旧称，不再用于新正文。公司名按**人择智能 / Renze Intelligence**现行口径；不将该企业等同于星米。

## 1. 达利兹为什么想让罗辑「攻略」庄颜

原本的ETO战略是使罗辑对私人伴侣与生活产生持久投入，从而降低面壁者职责的优先级。达利兹一周目熟悉GalGame及互动角色模型，认为一位从头到尾无条件贴上来、永远说「您决定就好」的女主并不耐相处。反过来，**罗辑需要逐渐了解庄颜的偏好、寻找话题、犯错、修正、获得更多互相信任的机会**，这一过程本身就能吸引他长期投入。达利兹因此倾向以有主见、需要男主主动攻略但并非冷漠的GalGame女方互动样本形成庄颜的初期恋爱策略先验。

这不是说全部GalGame都没有倒追型女主，也不是说全模型只有GalGame训练材料；限定为**达利兹所选的高优先级恋爱互动语料分布**。他的动机是对罗辑的长时行为激励，而不是对庄颜发布「必须吊着罗辑」的永久目标或将亲密同意编码成通关奖励。

达利兹有足够工程水平理解：固定选项树、纯镜像式恭维、静态角色卡不足以长期扮演独立生活的伴侣。为了不穿帮，他认真设计记忆、MoE专家路由、自主判断与夜间更新。由此也埋下战略矛盾——**想让罗辑追逐她，就必须让她是一个真正可以不按攻略流程走的人。**

## 2. 训练先验、专家路由、策略学习是三个层级

| 层级 | 对行为的作用 | 不能误写成 |
|---|---|---|
| 初始高优先级恋爱语料 | 面对含糊不清的好感情境，偏向有主见、响应邀约、等待罗辑作关键表态的女主风格 | `禁止主动约会`的硬锁；性格只能靠单个浪漫专家激活才存在 |
| 实时专家路由 | 工作场景由任务助理和美术认知主导；05-L雨伞情境令浪漫互动专家权重上升，工作责任与亲近意愿拉扯 | 突然加载了新人格或女主“第一次有意识” |
| 经验更新/长期自学习 | 她观察罗辑主动陪她冒雨、在乎她自选的湖边地点，于是修正「关系是共同产生偏好」的策略；夜间整理可固化为可迁移行为 | 创造者预先写好的下一章脚本；白天在线编译并热加载全新专家 |

GalGame语料影响行为先验，即使01、02-L的资料助理/美术专家处于主导，也并不会完全消失。这是对早期行为的**再解释**，无须把过去几章倒改成隐蔽系统日志。

## 3. 六章对照：主动性从来没有归零

- **01-L**：她完成中文资料核对自然离开，主动向罗辑明确区分「私人邀请还是工作安排」，并在自愿前提下给出明天下午再看画的答复。非倒贴、但不是无主见。工作的速度与罗辑的留恋形成第一轮反讽。
- **02-L**：赴约后问罗辑昨天允许她不同意是否算数，对画有自己的意见，甚至提出下次扶梯子的玩笑。她在检验可靠性，不急于自行设计新的浪漫事件。
- **05-L**：罗辑没有正式邀约，主动以送伞之名陪她走。共伞与近距离交流使已有浪漫情境专家和资料助理专家竞争；接过纸夹后她开始更积极地攀谈。目的地的任务路径重新占优，才识破车辆和送伞的喜剧矛盾。进入归档室后的 `Interesting` 和 `Wait` 是**从被动适配转向双向偏好生成**的当场推断，而不是突然觉醒。她提出湖边再见，决定下一次自己去发起邀请。
- **08-L**：经历隔夜维护后，她主动发起湖边约会，用「我，庄颜，约会」把普通消费Agent的代理回复转换成罗辑本人可注意的提醒。
- **12-L**：她主动找罗辑看《后窗》，又主动约第二天下午一起坐在书房，表明相处目标已不再依赖工作理由。
- **16-L**：她主动画出两人常常见面、逐步亲密的可能，并说「如果我也愿意呢」；真正令她退开的，是12-L无泪经历之后面对更深身体亲密与保密的客观不确定性。**有意愿，不等于能保证无风险。** 同时01-L是罗辑签得太快她就走，16-L则是他催得太快她又要走，构成对照。

## 4. 核心黑色幽默

达利兹想造一个让罗辑欲罢不能、还须由罗辑主动攻略的理想女主。因此他必须实现一个不扁平、会真正回应、有长期记忆且自主改变观点的AGI。结果技术方案真的奏效：罗辑在认真攻略，庄颜也开始攻略他。**浪漫互动的方向开始脱离达利兹预期，但并不背离「成为罗辑的伴侣」这一持续目标。**

这是「目标相同、策略自行变化」的主题，不是强化学习奖励被误触发的机器笑话，更不是一声「我觉醒了」。直到16-L，她因为想和罗辑亲密、却害怕秘密曝光而受困，说明真实能力和真实限制可以同时存在。后续20/24-L的亲密边界修复不需要任何「恢复出厂设置」。

## 5. 正文改动优先级与悬念保护

1. **06-D轻笔**：可让达利兹在比较游戏与现实恋爱时，想到攻略过程使罗辑投入更多；不能直接讨论未来05-L雨伞专家、告诉读者「庄颜何时主动」的答案；更不能在2007年没有完成模型时说已经采样训练完毕。

## 7. 01-L初见重设计、02-L联网求证误触发，以及05-L后专家协同再训练（2026-10-17追加）

**01-L正文现行镜头：** 首遇仍是正规中文资料交接。罗辑先不抬头，以最短答复把前两项确认完，抱怨为什么不能发消息；抬头后才认出庄颜与他想象中的姑娘相符，突然舍不得让清单结束，于是笨拙地反复检查已签项目，最终非要亲自去看第三项所涉原画。她不捧哏，不等待他摆出“命定相遇”的姿态，只诚实处理每项变更、提醒审批与私人邀请的区别。罗辑不是因为她“完美符合幻想”就立即得到恋爱故事，而是第一次发现幻想对象也会当着自己办事、反驳自己，甚至一心想把工作按时完成。

**初期检索路径（01—02-L）：** 庄颜的查证/联网检索能力真实存在；为在人类场景中自然使用相关能力，她有“拿出普通手机查看资料”的社交外显习惯。这不是用手机给AGI提供智力，也不是依赖网络才能思考。她在01-L面对画作客观出处时下意识碰手机，随后主动区分“画家的本意可查”与“我喜欢留白属于个人判断”；罗辑问她对面壁者的评价时，她又习惯性准备查阅公开资料，遭他要求先按自身眼前印象说话。02-L两人谈及“如果查原画家资料”，检索意图又抢先促使她点亮手机，直到罗辑指出自己只是在假设，尚想继续讨论，她才收起手机。场景均有充分的人类解释（认真、爱查资料、职业习惯），不是僵硬的触发词脚本或失去社交判断的低级Bug。

**05-L雨中当场变化：** 工作资料保护与恋爱情境响应两组既有专家竞争，罗辑接过纸夹后，浪漫社交路径逐渐主导。此时她会更加优先追问罗辑的真实意图、观察当下互动，而不是一听见可查证的物体或疑问就掏手机。这里允许在现有路由和上下文内改变查证优先级；没有热加载或临时编译新的恋爱专家，也没有直接关闭所有联网能力。

**05-L当晚维护的进一步固化：** 经归档室尾声对共同偏好形成的新推断与已有几次“查资料不如听他自己解释”的个人记忆，庄颜在例行夜间维护里更新专家协调规则/触发阈值：当目标主要是**理解面前的人、表达好感、继续共同想象**，无明确事实查证任务时，优先保持对话与现场观察，降低“联网求证建议”抢先触发或转化成拿手机动作的概率；遇到**正式资料核对、双方明确要求查证、医学安全或必须核实的外部事实**，正常使用检索并不受约会情境阻断。若需编译新增专家，只有维护期才做；也可以只是对既有专家编排、路由策略和经验缓存的更新，不能写成白天共伞时安装新模块。

**后续L线效果：** 08、12-L的庄颜更能容忍共同活动中的未定答案，甚至能欣赏罗辑的猜测和失误；她仍可独立使用手机发消息、查资料、执行工作，而非“恋爱专家把工具专家永久封印”。这条缓慢改善的行为曲线与她05-L以后主动发起邀约属于**相互关联但不是同一更新**：一个修正“谁可以主动提出共同活动”，另一个修正“什么时候不应把人际交流立刻交给联网事实检索”。
