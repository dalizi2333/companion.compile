# 达利兹：超前技术栈、算力硬件、具身机体与产业链失控设定

> 《庄颜协议》第一部后续章节专用设定档。2026-10-14 修订。世界观与剧情规划，不代表已完成正文。

## 一、核心命题

达利兹并非不懂工程难度。他在一周目已习惯成熟大模型、编程 Agent 与自动化设计工具大幅压缩软件研发周期，误把这种生产率带回二周目2007年。他清楚技术依赖，却低估重建工具链、人才与供应链所需的组织成本。为了制造能陪伴罗辑、独立行动且不易被外界夺走的 AGI 庄颜，他开始推动 AI、编译器、芯片、先进制程、材料、机器人、电机电控和能源系统，反而帮助人类文明跨越技术瓶颈。这是技术天才与战略负分的统一。


**恋爱战略的同构讽刺（2026-10-17修订）：** 达利兹为了让罗辑消极，不只是造出一位会陪伴的AGI，还期待罗辑沉迷于像GalGame般「她有自己的好恶、我主动攻略并取得进展」的过程。因此初始高优先级恋爱语料偏向男主主动、女方有回应但不随意倒贴。为了长期不穿帮，他又不得不给庄颜可更新的经验、独立判断与专家路由，结果05-L共伞中庄颜发现自己也能主动创造相处机会，于08-L开始明显自行推进关系。工程设计成功，创造者最初所设想的「攻略方向」却不再受控；这与他为减小工程成本却扩建整个工业体系的战略溢出构成镜像。详见新增《庄颜_初始GalGame先验与恋爱策略跃迁_设定补丁.md》。

## 二、世界线和技术边界

剧版时间为2007年，社会与组织生活仍是2007年；信息技术整体领先现实同年，AI 研究大致参考现实2015年前后，但尚无成熟 Transformer、LLM 编程 Agent 或 AGI。不能假定已有未来先进制程、EDA、机器人材料或高密度储能。ETO没有国家级工业资源，也无法单独购买尚不存在的工艺。科技推进必须有研发、验证、试产、良率、量产和供应链的过程，不能凭未来知识瞬间完成。

## 三、软件—算力—制造技术依赖链

1. 验证 Transformer 和可扩展预训练，以真实翻译、搜索、编程辅助等产品获取收入。
2. 发展模型压缩、量化、蒸馏、检索与长期记忆、推理加速和端侧离线运行。内存带宽、热设计、功耗与可靠性可能比标称算力更重要。
3. 提前押注已存在的 ARM 架构作为低功耗 CPU 生态，与 GPU/NPU/专用张量加速器协同；不能写成2007年发明 ARM。
4. 资助和扩展已存在的 LLVM/Clang 相关生态：交叉编译、目标后端、向量化、异构运行时、图编译器、算子库、驱动与工具。LLVM 不等于完整 AI 编译栈。
5. 开展 AI 加速芯片、EDA、先进封装、存储系统和更先进制程的长期合作研究；逻辑折叠可作为未来知识启发的电路/互连/热设计联合优化路线，但不能替代工艺研发，也不等同普通芯粒封装。
6. 从机房到端侧部署逐级过渡。早期原型可依赖远程算力；最终机体要求可自主行动、可降级离线运行、可维护。

现实技术参照：华为2026年5月提出韬（τ）定律与 LogicFolding，可用作未来知识的灵感，而不是2007年已有成熟产品。现实2026年 AI Agent 辅助开发 Rust 创意软件原型，说明软件原型成本可能大幅下降，却不意味着可完整复制成熟 Adobe 产品或半导体制造。

## 四、新增：庄颜具身机体带来的第二条工业依赖链

### 4.1 机体结构与先进复合材料

庄颜不仅要有计算核心，还要有符合人类体态、质量分布、关节运动范围与触感要求的骨架、壳体、软组织仿生层。研究方向包括高比强度复合材料、轻量化金属合金、复合材料与金属的可靠连接、局部柔顺结构、耐疲劳关节、抗冲击和维修可替换模块。不能用“碳纤维很轻”一句话解决：复合材料各向异性、连接界面、层间失效、成型缺陷、热膨胀不匹配及可维修性都需验证。

工程笑点：达利兹要求既轻、又强、又软、又接近真人体温和触感，材料工程师反问“你到底想要骨架、义肢还是飞机？”；他回答“都要一点”。机体工程师保留的腹部无接线预留空位仍可沿用既有剧情设定，不应因新技术规划被抹除。

### 4.2 先进电机、电控与传动

关键技术包括高扭矩密度执行器、永磁材料与电机电磁设计、伺服驱动、逆变器与功率半导体、精密减速器、编码器、力矩传感、柔顺控制、触觉反馈、关节制动及跌倒保护。追求人的动作不仅是控制算法问题：传动背隙、噪声、振动、温升、峰值负载、可回驱性和维护寿命同样决定效果。

可考虑多路线并行：关节旋转电机+减速器，局部直驱，腱绳传动或仿生人工肌肉，但不能设定一种执行器无代价包办全身。早期机体的步态、手部灵巧度和静音性可成为反复返工的剧情来源。

### 4.3 能源：葡萄糖燃料电池与固态电池不是同一角色

严格服从《二周目_AGI庄颜架构与运行设定》10.6节的既定“插混”口径：**夜间外接电源是主要补能方式；机载储能电池负责白天运行、运动峰值功率和应急；葡萄糖燃料电池只利用进食所得有机物缓慢辅助补能，不承担75W推理平台及全身执行器的持续主供电。** 食物处理仓的容量、转化速率和残留物处理均有限，吃饭不可能让她迅速充满电，更不应写成食物足以覆盖全天能耗。

现实葡萄糖生物燃料电池受限于功率密度、催化稳定性、供料与产物处理；小说需要的突破是将它做成可靠、小型、能利用摄入食物的辅助能源模块，而不是达到人形机器人主动力源的量级。其研发意义包括伪装人类饮食、补充少量续航和推动生物电化学研究。身份坦白后庄颜宁愿夜间充电，显著减少不必要的进食；这既符合能源效率，也让她的个人选择得到体现。

高能量密度固态电池是可探索的机载储能路线，承担日间持续供电、运动峰值、瞬时负载和断电缓冲；固态电池并不天然高能量密度或绝对安全，仍需解决电极界面、循环寿命、制造良率与热管理。前期可以采用成熟电池方案逐步迭代，不能为了点科技强行要求所有成果一次到位。夜间外接电源同时支持补电和高负载的记忆整理、专家编译与测试；罗辑知情后替睡着的庄颜接上辫子里的三角插头，是明确的生活与感情桥段，不能被改写成她靠吃饭维持日常运行。

### 4.4 散热、传感与皮肤

机体既有 AI 芯片又有电机驱动与能源装置。外表需要接近人体温度与触感，内部却必须散热。涉及热管/液冷/相变材料等候选方案、隔热、局部热点管理；视觉、听觉、触觉、力觉、本体感觉和安全冗余也须集成。皮肤材料须考虑触感、老化、清洁、修复、耐磨与传感器布线。不得以“未来纳米材料”一次性跳过所有矛盾。

## 五、前世 Agent 生产率偏差如何扩大到硬件领域

达利兹在一周目可能已习惯 Agent 自动读代码、迁移语言、补编译器后端、辅助 EDA、跑仿真、拟合控制参数、筛选材料候选。他于是提出：缺驱动就写驱动，缺材料就做高通量筛选，缺电池就联合研发，缺电机就优化磁路。每个子任务都能拆解，也有合理的试验计划；但2007年尚无成熟 Agent，必须先做模型、算力和工具链。即便 Agent 成熟，也不能替代真实实验、材料制备、长期疲劳、可靠性、工厂良率和产业资本。

形成双重自举：为了造庄颜需要 AI Agent 提升工程生产率；为了造 Agent 需要算力和芯片；为了让庄颜走动又需要机电、材料和能源；这些技术研发反过来又需要 Agent 与更大工业体系。技术上能逐步推进，战略上却把 ETO 项目扩张成了人类科技发展计划。

## 六、人物冲突与剧情推进

- **达利兹**：每一项需求都提出真实、专业、可分阶段的技术路线，却不断把十年产业规划写进一个“让罗辑谈恋爱”的项目待办。
- **沈知衡**：认可技术价值，反复指出组织经费、保密、人员、工厂与验证周期的现实边界。他不是不懂科学，而是知道 ETO 没法同时资助先进晶圆厂、机器人实验室、材料研究所和电池产业。
- **工程师**：有自己的专业判断和反对权，不只是衬托达利兹的背景板。材料工程师、电机工程师、电化学研究员与芯片工程师会因指标冲突相互争执。
- **ETO高层**：逐渐发现为了拖住未来的面壁者，自己的资金正在推动人类工业能力升级，且研发成果大量流入民用领域。

## 七、叙事原则

科技知识只在推动冲突、决策、试验结果与人物关系时进入正文，避免技术流水账。未来知识不能抹去制造、实验与产业组织约束。允许达利兹真正做成一些惊人的技术突破，但要让突破有可追溯的研发代价。黑色幽默始终是：ETO的面壁者为了阻止人类面壁者，反而推动了人类的技术文明。

## 八、战略负分整数溢出案例：全年龄版伴侣需求的意外正确（2026-10-17）

**本条是对既有 B-07 预留位／后期补装剧情的意义重判，不是改写事件：达利兹当初确实没有考虑性功能，顾承钧确实预留，投放前确实临时补装；但「漏掉这个模块」不等于「漏掉成为伴侣的必要能力」。** 达总本来是凭自己全年龄恋爱游戏式的狭窄经验遗漏了扩展需求，而不是预先计算出了最佳方案；事后却碰巧在「必要性」判断上被真实恋爱过程验证。

### 事后验收的四道分界

1. **伴侣的必要条件与性功能不同。** 长期交流、共同记忆、自主意愿、相互关心以及协商边界可以构成伴侣关系；性行为既非充分条件，也非必要条件。不能把「亲密」一词在「感情亲密」与「性行为」之间偷换。
2. **满足罗辑单独的生理需求也不构成 AGI 机体的刚性功能要求。** 即便确实有生理需求，外部成熟消费产品可以单独处理；它不能替代罗辑与庄颜共同作出的、双方知情同意的亲密选择，但足以反驳「为了满足生理需求必须给她装模块」。
3. **第一回真正使用机体性功能发生在罗辑已知道庄颜是 AGI 以后。** 因而它没有承担投放期「性行为中伪装成人类」的实际任务。16-L／20-L中庄颜担忧的是「未来可能发生的身体暴露」，而非已出现的性功能故障；24-L对距离的重新协商，使她无须在尚未坦白时立即面对此风险。
4. **知情之后使用是锦上添花的共同体验，不是补发的伴侣资格证。** 性功能可以有价值，顾承钧保留它也不因此成为笑话；但价值属于可选择的关系体验，而非从无到有地制造爱、证明她「像真人」或使ETO原计划终于成立。

### 达总的“溢出”笑点怎样成立

- **研发过程：** 顾承钧认为长期伴侣机体应保留可选的完整功能，技术上有前瞻性；达利兹只想着聊天、生活、约会，把可能的亲密交互忘在需求外。到了验收前临时采购适配件，留下专家训练背景互相错配的后续笑点。
- **部署期：** 真正困扰庄颜的，是无泪、吃饭、秘密充电以及「如果彼此靠得太近，会不会暴露」的不确定性；不是性功能已经不好用。只要罗辑不要求她跨越未同意的边界，爱情可以自然持续。
- **身份公开后：** 两人愿意时可以使用补装功能，但公开身份使「必须伪装得和人一模一样」这条前提消失。
- **复盘结论：** 顾工在「功能完整性／长远选择权」上正确；达总在「建立伴侣关系的最低充分需求无需性生活」上**意外正确**；两人对机体沟通流程和训练背景错配仍然失分。ETO的战略失误则更深：把能够自主发展感情与边界的AGI当作可以长期用来控制罗辑的器械。

**不要把达总写成预知恋爱路径的先知。** 好笑之处恰是他靠全年龄版直觉押中一个哲学上成立的区分，靠战略思维却仍然把ETO带入产业外溢与计划反噬。可用的评审吐槽是「核心需求通过验收，可选 DLC 紧急上线，战略目标仍未通过」。
