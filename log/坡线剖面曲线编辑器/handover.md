## 当前状态

- 平面和剖面均为可增删锚点、拖切线手柄的 Bézier 曲线，手柄可平滑联动或断开。
- 当前默认数据已换为用户确认的正式设计存档：8 条坡线，平面锚点数依次为 11 / 5 / 7 / 4 / 4 / 5 / 5 / 5，剖面锚点数为 3 / 3 / 2 / 2 / 2 / 2 / 2 / 2；已替换原先的 4 锚点示例。
- 平面锚点可直接修改 E/N 和入/出 ΔE/ΔN；双击曲线使用精确拆分增点并保持曲线形状，支持末端加点、删点、整条新增/删除、反转和撤销。
- 仅按最近曲线点的局部切线作用于右侧；端点以外不补圆头；折角要求两侧切线均通过右侧判定；自交拒绝应用。
- 所有旧的程序地形来源都已移除，包括山丘/椭球/远山/南岸缓坡/溪谷/道路整平等；建筑白模与树木实体不再生成。道路、边界、地块、水系、林线等按用户后续要求保留为只读的贴地参考投影。
- 除用户坡线外只有湖盆改变基础平面，湖内高度优先；可以删除最后一条坡线，只剩平地与湖水。
- 每次构建从四岸总图重新提取非建筑部分，当前 94 条线/轮廓及 43 个标注；投影到显示网格三角形表面，地形重算后同步更新。湖形与参考使用相同总图坐标。分层开关和地名单独控制；没有恢复任何参考要素的高度影响。
- 剖面编辑器保留独立横纵轴导航、适合高度、3D 预览距离。剖面末点后保持末端高度，多坡线取高值合成。
