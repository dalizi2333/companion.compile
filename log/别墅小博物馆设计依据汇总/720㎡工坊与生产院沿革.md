# 720㎡主工坊与1184㎡生产院沿革（本轮现行）

> **烟囱与打铁炉现已落到拓扑：**见[定点记录](烟囱与打铁间_拓扑定点.md)。VC1—VC8、逐炉烟道与工坊西南36㎡砖砌修配间均已定位置，不再由生成器决定。主工坊与生产组面积不变；当前55空间块。


2026-11-06。用户明确采用720㎡主工坊、整组1000—1200㎡，要求保留水力棚与工坊的动力联系并更新年代史。本稿只更新生产院；家庭住宅、四间可住卧室、20-L西翼餐厅及空中花园不扩大，不改正文或现场地形道路。

| L1 有顶装卸／堆料棚 | 14×8m | 112㎡ | 敞开装卸、长料临放，后继续后勤使用 |

| S1 旧锅炉房＋S2旧蒸汽机房 | 各8×8m | 128㎡ | 后改账房、档案，再为馆务归档和办公室 |

1184㎡包含1072㎡封闭/后期封闭空间和112㎡有顶敞棚，不能将其全称为室内面积。锅炉、蒸汽机附屋已纳入1184㎡，不是另在1200㎡之外追加。

1890年代转型供水后才添的64㎡营业仓、1998—2006的144㎡专用保存附屋不追算成早期木工生产组。一般大件可放修缮后的旧材仓，纸本/小件、胶片长期保存与检片仍按不同环境分室。

## 地点与物流关系

主工坊保持南边界Z=-18m及东边界X=0不动，向西、向北扩到X=-30～0、Z=-42～-18m。住宅—工坊联系廊仍接工坊南门。整组留在住宅北侧，不挤入家庭院落。

- 水力棚X=-38～-30、Z=-42～-34m，共享工坊西侧8m墙段。
- 材仓X=0～8、Z=-42～-22m，与工坊东墙有2.6m内门。
- 装卸棚X=0～14、Z=-22～-14m，北连材仓南门，西连工坊3m运输门，东侧向生产院开放。主工坊、材仓、装卸可直接周转，不穿住宅。
- 旧动力附屋与后来的营业仓移至工坊北侧Z=-50～-42m；保存附屋顺移到Z=-59～-53m，留3m后勤通道。

主工坊用三跨屋顶表示，概念檐口/生产净高工作值约4.5m，分跨柱位用于表达生产建筑；没有将720㎡理解成无柱大厅。材料仓暂取4m，装卸棚3.8m。上述是体量及拓扑候选，不代替跨度与构造设计。

## 动力联系不能只靠邻近

### 水力阶段

水力棚机械输出 → 共墙轴孔 → 工坊北侧总传动轴 → 分支轴和皮带 → 分区机具。

共墙人员门在(-30,-36)，机械轴孔在(-30,-39.2)，两者分开。总轴从水力棚X=-34延伸至主工坊X=-4，标高工作值3.4m；三组支轴向南服务不同工位。页面早期阶段显示轴、带轮、支轴和机具占位。

720㎡还包括长料、装配、成品周转和通行空间，不能按面积推算所有机具同时运转。水量、水头、轴系损耗、机组功率与运行方式留待设备设计，不因扩大面积就宣称既定水车必然有足够输出。

### 蒸汽与发电阶段

1880年代机房位于北侧，另一路机械传动穿工坊北墙，在(-5.5,-42)接入同一总轴；这处轴孔与机房人员门(-4,-42)错开。蒸汽用于何种季节/工况的具体排程尚未锁定，不凭示意图认定水力与蒸汽必须同时全负荷运转。

1890年代拆旧蒸汽设备、改水力发电后，原跨墙总轴系统退役。现行馆务阶段保留轴孔遗迹和人员内门；馆务办公室沿用原机房、归档沿用原锅炉房。旧锅炉转卖南岸仍为候选，与南岸1890—1898年西翼工程对齐，精确年份待定。

## 统一后的年代史

| 年代工作值 | 生产与住宅变化 | 图上如何表示 |
|---|---|---|
| 1840—1855 | 先有一家小住宅及院地，家庭劳动起步 | 原小宅，不预先建成厂区 |
| 1855—1860 | 院地搭棚木作，逐步建设水力棚、引水和尾水联系 | 属1855—1870复合阶段的起点，未锁起棚尺寸 |
| 1860—1870 | 加固扩展干加工/装配主工坊至720㎡，补材仓、敞棚，水力机械传动成组 | 该阶段按钮显示形成后的1056㎡核心；不是第一天即建720㎡ |
| 1870—1880 | 木作经营兴旺后改善家庭住宅，保留普通家庭房与少量留客 | 住宅沿家庭收敛版，未增加客房排楼；架高花园年代仍是该阶段设计候选 |
| 1880—1888 | 取水池/工坊附近添锅炉与蒸汽机，各64㎡，接已有轴系 | 总生产组1184㎡，显示蒸汽支传动 |
| 1890—1895；工程可延至1900年代 | 转型供水，拆售蒸汽设备、水力棚分期改发电，原机房转账房；后加营业仓并另购地建水利工程基地与食堂 | 轴系退役留痕；营业仓与独立工程基地不倒算为早期木工组 |
| 1925—1935 | 较晚从工坊电引住宅支路和电热床具，生活条件分步改善 | 不倒推原卧室已有地暖或全面电热 |
| 1955—1965 | 本版热泵改造候选，远置仓棚改设备房 | 旧锅炉/机房仍为账房，不占回 |
| 约1970收购后逐步改馆 | 720㎡旧主工坊修缮为陈列厅，160㎡材仓在改善围护和防潮条件后改大件保管；原住宅保留家庭房、普通客房和餐厅 | 不把原潮湿材仓未经改造直接当专业片库 |
| 1980—1990年代前期 | 部分家庭胶片可转录录像带 | 收藏技术变化，不单独新增大栋楼 |
| 1998—2006 | 营业仓改数字机房，增纸本/小件、胶片长期库及回温检片附屋，接庄园光纤 | 专业保存与热设备分别控环境，重要扫描可委外 |

相对顺序沿用用户确认。除约1970收购等已有锚点外，具体起止年仍为创作工作值；本轮没有改正文。

## 水系与空中花园

工坊向北扩大后，水力棚、动力渠和尾水一同北移：北侧来水→取水池→贴邻动力棚，尾水继续向北返溪。住宅污排、旧厕屋污排、空中花园回水的终点随下游示意段调整，仍避开上游取水。花园供水支管仍接既有取水池，标高/自流能力和独立溢排细节另核。

## 当前面积汇总与验证

住宅938㎡、住宅—工坊联系廊30㎡、旧木作生产组封闭空间1072㎡、后加供水营业仓64㎡、专业保存附屋144㎡、远置热泵/旧厕屋56㎡，合计**室内2304㎡**。另有装卸敞棚112㎡及原分层室外空间211.95㎡，室外/敞开部分合计323.95㎡，不代表同等新增占地。

53个空间块＝47室内＋6室外/敞开。住宅、四间可住卧室、西翼48㎡餐厅与84㎡空中花园不变。

已核对同层无重叠、室内有门且门中心在墙线；主工坊、水力棚、材仓、装卸和旧机房之间的门/轴孔对齐。总面积核算1184㎡，主轴、支轴和蒸汽接入按阶段显示。页面构建无运行错误，生产院及早期动力截图已检查。此文覆盖旧384㎡工坊与相关旧生产院坐标，家庭部分仍按收敛版及空中花园末节执行。
