## 一、统一后的年表

| 年代工作值 | 原业主生活与经营 | 留在现图的建筑层 |
|---|---|---|
| 1840—1855 | 东岸只有一家人住的小房子和院地，以家庭手工与小规模经营起步。早于1890年代转型所需的具体起点由本版暂拟。 | 两层8×8m旧宅；一层厨房、门厅/紧凑主梯、小书房、餐室、客厅，二层卧室。128㎡合计，先满足日常居住。 |
| 1855—1870 | 空地搭棚做木工，逐渐形成较大的干燥木作/装配工坊；溪谷另设水力加工棚，修上游引水与下游尾水渠，可有小取水池。 | 96㎡干作坊、30㎡水力棚；取水池与动力渠线。阴坡、台地、陡岸与溪谷各用其长，不把整片地当良田。 |
| 1870—1880 | 增建家庭卧室与小起居室，仍烧炉子，没有铺地暖。**新增卧室本来就有厕所设计**，不再写成住进来后才把储藏室改厕所。 | 西侧两层生活扩建、独立侧梯、上下短廊、客房套内厕洗、家务空间和露台。盥洗/厕所的具体装置不锁为现代冲水制式；后世才更新热水和洗浴。旧宅老厕屋另保留。 |
| 1880—1888 | 工坊附近、取水池一侧添蒸汽动力。优质木料继续加工增值，燃料并不宽裕，设备成本成为后来转向水力的动因之一。 | 21㎡锅炉房＋21㎡蒸汽机房；机座、轴孔、烟道和补地面可保留改用痕迹。功率、燃料库和水力备用关系待定。 |
| 1890—1895；工程可延续至1900年代 | 筹办城镇供水，拆蒸汽设备，水力棚分期改发电；原机房改账房。**旧锅炉卖给南岸是本版保留的候选**，对齐南岸1890—1898年西翼工程，具体拆售年暂不锁。转型后才购入南岸其他业主土地，建工程基地、职工食堂和配套。 | 旧动力房转营业账房/档案间；添营业仓房。工程食堂后来的宴会厅/中央厨房在别处，本图不把住宅或木工坊改成宴会厅。支流取水池与出湖蓄水坝是两套不同尺度的设施。 |
| 1925—1935 | 工坊已有电并不等于家庭马上全面电气化。本版将住宅支路、电热床具等较晚生活改善放在此期，炉具继续保留；少数后加水暖另记。 | 工坊供电引到住区；保留原炉位与烟囱。具体首次通电年、电制和电热床具采购年待核。 |
| 1955—1965 | 本版先采用“原业主晚期补全屋热泵”的候选，以改善老房间，不拆木楼板重铺地暖。此日期不是用户已经锁定的事实，必要时可整体后移到收购后。 | 远处16㎡工具仓棚改热泵房，距最近住宅约21m；室外换热部件与检修也放在远端。旧锅炉/机房继续当账房，不占回。 |
| 约1970年；1970—1985逐步改用 | 南岸家族买下邻业主住宅、营业附屋、相关地块与铁路资产。收购时窄轨仍在运营，接手后才决定停运、适合路基改公路；供水/坝务权利另安排。随后把工坊与附屋逐步改馆。 | 工坊→主陈列厅；原账房→归档与馆务；住宅保留小餐室、备餐厨房、客房和小起居室。改馆并非一夜完成，后续1990年代仍继续更新。 |
| 1980—1990年代前期 | 部分家庭胶片可转录录像带；不据此推导已经有现代数字机房。 | 是收藏技术变化，不必新增一整栋楼，故模型没有单设此项扩建按钮。 |
| 1998—2006 | 数字目录、数字母版/播放服务、私人服务器和庄园光纤逐步形成；39-L的Agent服务器在小博物馆，主楼只留终端与交换设备。 | 营业仓房→30㎡数字机房；后加一般藏品库、专用胶片库、回温/检片整备各20㎡，走独立后勤通道。普通藏品、胶片、机器发热空间分别控环境，设备形式待细化。 |
| PDC接管及故事期 | 庄颜来做临时资料核对，在主楼、北岸附楼及别墅间往返，别墅西翼保留独立客房。 | 05-L签收、08-L门前与草地、20-L小餐室、24-L客房/窗/楼梯/起居室/露台、39-L机房、42-L回忆均按原归属保留。 |

这不是同一位原业主活了一百多年：早期建房、木工经营、供水转型与生活电气化属于东岸业主家庭的几代经营。收购后的收藏改造属于南岸家族。

## 二、从住宅推导现用拓扑

南侧朝湖只作独立设计坐标，X向东、Z向南。住宅居南、旧工坊与水利附屋居北，分别形成体量，通过5m长联系廊相接；不是先造大博物馆再往里塞卧室。

- 原宅 H：两层128㎡。原厨房仍服务临湖16㎡小餐室；原客厅16㎡可作住宅历史展室。旧宅上层保留原家庭房间尺度，改小型研究/访客/展示，并补公用厕洗。
- 西侧生活扩建 A：室内285㎡，含15㎡工坊联系廊，另有19.8㎡露台。楼下备用客房从房内进配套厕洗，家务洗衣另从短廊进；楼上庄颜客房33㎡、套内衣帽14㎡、厕洗19㎡、小起居室33㎡，以短廊和侧梯联系。
- 干作坊 W：96㎡单层大空间，现为主要陈列厅，保留屋架、旧柱位及运输大门的可能。
- 水力棚 P：30㎡，先加工动力，后发电；机组及落差需要随场地另排。
- 旧蒸汽附屋 S：42㎡，转账房后成为归档/馆务。营业仓 N：30㎡，后期改数字机房。
- 后加保存附屋 M：60㎡；与原账房/仓房间留2m后勤通道，每间独立开门，不把机房作过厅。
- 远置设备及旧厕屋 T：热泵房16㎡，旧厕屋6㎡。

本版34个空间块（含露台），室内概念面积693㎡＝一层494㎡＋二层199㎡；另有19.8㎡露台。面积按空间矩形累计，未另计墙厚，不是报建面积。原宅与生活扩建/短廊合计413㎡，其余280㎡是分期生产、营业、保存与设备建筑；不能将693㎡称为一栋原始“小住宅”的面积。上一版795㎡不再作默认规模。

## 三、正文走位及门

### 24-L

庄颜客房东门 → 2.4m宽厅廊 → 南端朝湖窗；北侧是侧梯上层平台。房门至湖景窗直线约6.6m，按图示折线行走约7.3m；窗至梯口约10m；房门至上层踏步口约5m。能够听到走廊说话、开门冲近梯口，也有离开梯边后的停步空间。具体演出和梯口护栏在楼梯详图复核。

小起居室在客房南侧，另从短廊进；房门不直接连起居室。沙发可躺人，对面有椅，茶几可放水杯；起居室南玻璃门直通露台。走廊尽头窗和露台门分开，露台不挡窗前草地视线。

### 05-L

沿外侧湖边步行线 → 西翼侧门前厅 → 向北的联系廊 → 北侧旧工坊 → 原账房归档。签收人员可在入口值守窗接收材料，办公室在后；初始“西翼归档室”是这组西侧复合空间，不要求把所有归档工作都安排在西门厅。陆侧车辆到后勤院，不穿住宿房间。林木、短檐与行车绕行比例随实地落位安排。

### 20-L及08-L

原家庭餐室保留16㎡，与厨房相邻、有独立门和湖侧门窗；给两人桌、椅背外套、文件及服务退出留位置。它与主楼临湖餐厅、工程食堂后来的宴会厅是三处不同空间。

08-L草地在住宅南侧、24-L窗前，画面湖景开阔、栏外陡岸；模型只标窗景方向，不先改现场道路和坡坎。

## 四、取水与污排：本轮用户纠正

业主自己经营供水，生活污排不能回到湖泊水源或上游取水渠。**住宅新增厕洗与下游老厕屋的污排分别汇往取水点下游，回入溪流**；图中棕线明确接到下游青色溪流延伸段，不以不明终点代替。

动力引水、尾水与生活污排分别画线，不把厕所管直接接入取水池或上游动力渠。污排回溪属于历史用途叙述；具体接入高程、管沟、历史装置和后世治理尚未设计，不把图上折线当工程排水图。新扩建卧室初建即含厕所，取代“后改储物间补厕所”的上一轮假设；后期洗浴与热水设施的升级仍可保留年代差。

## 北侧生产与水系落位修订

用户进一步明确：旧工坊与水利设施可放住宅北侧，来水从北接、尾水仍往北排。现行模型已将旧工坊、旧蒸汽附屋/账房、营业仓/机房及后加保存附屋整体北移；水力棚、取水池和老厕屋也移到北侧工作院。住宅房间及24-L走位未移动。

北侧上游来水 → 取水池 → 动力引水 → 水力棚 → 向北返回溪流下游。模型以北侧一进一出两条线路表示，不再把尾水或污排朝南面的湖岸导引。住宅及老厕屋污排向北汇入取水点下游溪流，避开干净引水段；上下游以溪流流向定义，不以地图北/南代替。渠线转折、水头与标高后续落地形时再校核。

工坊与住宅间留6m联系廊（3m宽、18㎡），替代旧3×2m短廊，因此总概念室内面积增加12㎡至578㎡，房间数量仍33块。道路未改。

水力棚与木工坊关系进一步落实：水力棚贴邻工坊西墙，共用6m墙段；设1.1m人员内门，另在共墙预留机械传动位置。早期水车经传动轴/皮带为工坊机具供动力，水力棚本来就是生产配套动力间；1890年代改发电后，原跨墙机械传动退役，轴孔遗迹与人员联系保留。北侧来水、北侧排水关系不变，建筑面积不变。

## 西翼正式住宅尺度修订（本轮现行）

用户指出西翼仍像小客房附楼，不像经营已有规模后扩建的大户住宅。现将1870—1880年代工作阶段理解为东岸业主家庭改善主居条件：9×15m两层西翼，上下各135㎡。原8×8m旧宅保持原尺度，呈现先小宅、后宽裕主居翼的年代差。新卧室仍用炉具，未因空间变大而提前加入地暖、电热床具或热泵。

- 二层原主卧33㎡、套内衣帽14㎡、厕洗19㎡，合计66㎡，后来为庄颜客房套间；厕所在扩建时即有，热水洗浴后世更新。
- 二层家庭起居室33㎡，厅廊宽2.4m，侧梯厅12㎡，临湖露台约20㎡。起居室保留沙发、茶几、对椅、书柜及露台门，不从卧室直接穿入。
- 一层西门厅/会客33㎡，备用客房33㎡并配19㎡套内厕洗，另14㎡家务布草房和独立厅廊；收购改馆后门厅承担05-L值守签收，向北经连接廊到旧工坊和账房。
- 北侧工坊、水力棚的人员内门与机械传动位置不动；联系廊因住宅北边界延伸而改为3×5m、15㎡。

当前34空间块，室内693㎡＝一层494㎡＋二层199㎡，另19.8㎡露台；其中原宅与西翼共398㎡，加15㎡联系廊合计413㎡，其余280㎡为生产、营业、保存和设备附屋。此前33块/578㎡、18㎡客房、18㎡起居室和6m连接廊均为被覆盖的过程稿。概念面积不另计墙厚。
