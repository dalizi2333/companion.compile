# 当前第六版：西北灶间、后侧柴棚与斜向前梯

2026-11-07。当前北岸管理院落_场地试摆.json version 6；预览庄园三维体量模型_v3.html?focus=north-yard&rev=north6。第五版及其补正已存第五版记录.md，不能用其中的柴棚与前梯坐标覆盖当前版。

用户指出原斜向楼梯可用，应移动原灶间/柴棚附属体量，使之与西北烟囱对应。本版据此恢复斜向前梯，而非为前立面错误的柴棚位置继续迁就行人路线。

- 原灶间位于N11主体内部西北端，建筑旋转前候选矩形[-8,-31,10,7]。既有烟囱中心[-1.1,-28]保留；其世界方位依N11自身heading=0换算，不能把北岸场地heading45°的局部轴直接当作真北。
- 原前侧附属体量撤销。N11_K明确改为原柴棚/现勤务小库，转到灶间后侧，矩形[-5,-34.6,6,3.6]，同食堂楼面19.9m；主体后墙上的原灶间通门在[-2,-31]，柴棚侧面的搬柴门在[1,-32.8]。柴棚不设灶，灶与烟囱留在主体中，避免“烟囱在一端、柴棚和厨房却漂在另一端”。这些为关系与工作占位，非历史测绘或防火施工验收。
- 既有后勤搬运坡道保留，到后门平台再分出1.8m宽短平台通柴棚。附属地面局部找平，不占用上方后勤院或山脚马道。
- 前梯恢复朝院内斜向下降，底平台为场地[10,-9]，35级×160mm、12+12+11级及两处1.2m休息平台保留，踏面随选线约317mm。对照早期[12,-9]脚点，略向内退2m给食堂墙角和下平台留空，不把脚点直接卡在外墙/檐边。阶脚联络路先下移再接[24,-2.63]平交点；旧宅台阶不随意移动。
- 总图增加“柴棚与原灶间”后侧视角，可同时看烟囱、后门与小附屋；原“食堂入口高差”视角能看见腾空后的前立面和斜向台阶。
