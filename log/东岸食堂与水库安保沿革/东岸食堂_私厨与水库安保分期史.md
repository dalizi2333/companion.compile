# 东岸食堂、私厨餐厅与水库安保分期史

2026-11-07。本轮先定历史与用途，不定建筑尺寸、厨房设备容量或具体落位，不改正文。沿用约1970年收购、1972—1976年公园化及1995—2006年地产接待设施更新的既有工作分期；其他扩建与改造年份仍待细定。以下为本作的虚构建筑沿革，不作为挪威真实遗址的考证结论。

## 1. 两条建筑来历，共用一个水利经营背景

东岸原业主先经营木工和水力工坊，后转型供水与运输；转型后才向其他地主购入尚不属于南岸家族的地块，建立施工、维护和运输基地。此处食堂与安保用房属于该经营基地的公共后勤，不是原业主住宅的餐厅，也不是从小别墅的家庭厨房不断放大而来。

本轮明确两条相邻而不混同的沿革：

- **食堂—厨房线**：水库工作人员食堂／伙房 → 收购后公园工人供餐 → 逐步加入预约私厨／宴请 → PDC时期内部员工餐与获准接待。厨房为共同服务基础，大厅可随桌椅与使用时段切换。
- **看守—值班线**：水库安保看守及工程出入管理 → 收购后公园接待、设施巡护与物业值守 → PDC外围出入和值守联络。坝务技术值班仍有自己的工作位置，不等于门卫换一块牌子就接管了供水设施。

这里的“东岸”沿用庄园功能分区叫法；经营基地可能占收购进来的东端／东南侧沿岸地块，不据字面把它强塞回小别墅高台或取水设施旁。

## 2. 分期年表

| 分期 | 食堂与厨房 | 水库安保与值班 | 后来仍能看见的理由 |
|---|---|---|---|
| 19世纪末水利工程筹建与施工阶段（约1890年代工作分期） | 先有面向工人的伙房、共同进餐和避雨集会空间。施工高峰扩充灶间、柴料与食品储存，工人按班次吃饭；不把今天所有餐饮设施一次建齐。 | 对设备、材料、取水和闸门相关区域看守，照看工地来人、钥匙和夜间情况，并为事故、天气或停工提供联络。看守和值守是水利经营岗位，不设成庄园家族的私人哨卡。 | 大共同厅、独立伙房、后勤院与耐用服务入口；早期看守小房、钥匙柜及后加电话位置。 |
| 工程完成后的长期供水、坝务维护与运输阶段 | 施工人数回落后仍给水库运行、维护及有关运输人员供餐。大食堂兼作交班、恶劣天气停留和临时人员集会，季节检修时又会忙起来。 | 东岸在水利经营期已建护水源的入口主哨与安保起居、轮班过夜用房。另设清雪器具棚与封路储备仓，清雪器材随轨道整备归南岸旧整备场，改公路后东岸另建道路除雪车库。坝务继续独立技术值班。看守人员发现异常后联系负责操作、维修的人；不把安保和坝务工程师写成完全相同的工种。 | 一栋比常年在场人数所需略大的旧食堂合理存在，不必解释为每天满座；值班与餐食依然相互支撑。 |
| 约1970年出售、收购与道路转换 | 食堂、伙房和相应经营基地设施随本次交易中的资产安排接手；既有供餐能力先维持，不为了住宅收购而把工人食堂立即拆掉。铁路停运、路基改公路后，后勤收货逐步改由汽车承担。 | 东岸已有看守、等候、登记和联络基础，可转用一部分房间／岗位承担收购后物业值守与来访接待。供水、取水和坝务仍按保留的使用与维护安排工作，资产归属和维护通行不混为一谈。 | 旧收货面能改卸货，旧值班房能改接待；留下车辆时代的后改门洞、雨棚或铺地，不要求它们全属原建。 |
| 1972—1976年起，公园开放与工人餐厅阶段 | 原食堂继续给公园园务、清洁、维护、运输及相关当班人员供餐，称作公园工人餐厅。不是把所有游客都引进员工吃饭和后厨区域。北岸的原劳工食堂在集中供餐转到这里后，逐步转作活动杂物库。 | 水库看守体系中的可用房间与人员联络经验，承接公园接待、设施巡护、失物／求助转达、物业钥匙等日常事务；坝务技术区继续按其实际用途管理。公共通行、公园服务和进入住宅的预约接待分别处理。 | 接待等候区与员工后勤通路并存；游客可以得到指路和帮助，不把开放公园默认画成军事管制区。 |
| 后续经营发展，尤其1995—2006年预约餐饮更新 | 原有供餐基础逐步增加私厨餐厅、预约宴请与小型活动服务。主厅保留可调桌椅，也可补少量较安静的接待小间；厨房逐步完善储藏、冷藏冷冻、清洗和备餐。公园工人仍要按班次吃饭，预约餐饮不是把员工从原场所赶走。 | 东岸接待和值守也负责预约信息转达、车辆抵达、交接钥匙和服务联络。对外来客抵达与后勤卸货可分流，不能让保安桌变成厨房收货台，也不能让私厨客人穿员工更衣区域。 | 宴会厅的体面前场、旧食堂的大空间和仍在工作的中央厨房可以来自不同改造期；玻璃廊门、安静外廊和现代照明可以属于后加接待改造。 |
| PDC接管与故事期 | 停止常规对外经营；厨房承担驻地人员、客房与获准宴请的集中备餐，主厅日常作员工餐厅，正式接待时切换为宴会厅。27/31/38-L中央厨房、38-L员工用餐与60-DL晚宴均有共同建筑基础。 | 东岸承接外围出入管理和接待联络：既有接待／值守设施可利用，PDC沿用并升级水利经营期已有的主哨，现行哨位须服从对外道路与内部分流点的关系；坝边技术值班与维护通行另留。历史看守并不天然等于现代完整警卫系统。 | 接管以既有后勤与接待能力为底盘做调整；不必为每类人员再造一栋餐厅或一组新的警卫基地。 |

三个用户指定用途均保留：**水库工作人员食堂、公园工人餐厅、私厨餐厅**。时间上不是三个互相排斥、每次彻底清空的阶段；后两者可以在同一时期按房间和时段并存。现代称“宴会厅与中央厨房”，不抹掉前两层历史。

## 3. 东岸安保具体承接什么

“水库安保在东岸”用于解释已有看守、联络和出入管理设施的来历。收购以后可以复用：

1. 值班小房、电话／后期终端、钥匙及日常记录存放。
2. 工程来人说明身份、等候负责人的位置；后改成物业接待与预约来访联络。
3. 看守休息、交班、雨具和少量日常用品；供餐由原食堂支持。
4. 沿设施、道路与园地巡护的人员联络；发现设备或游客异常后通知相应负责方。

仍应区分：

- **坝务技术值班**：对闸门、取水和维护负责的岗位与房间，不拿来填宴会包间或私厨厨房面积。
- **物业／公园接待和值守**：处理访客、求助、钥匙与服务联络，可由历史看守设施逐步转用。
- **PDC外围主哨**：唯一常规陆路入口，须位于内部车路分流点之外。沿用水利经营期为保护水源设立的入口主哨。原址是否随铁路改公路调整，留待交通分期设计。
- **私人区边界的小哨**：继续沿既有四处越界节点理解，不因为增加水库看守史而改哨位数量。

上述是岗位、建筑和交通关系的沿革，并非要求把所有值班、维护和安保活动塞在食堂内，也不是把收购变成供水、湖位或公共通行的任意支配权。

## 4. 与北岸N5的关系

东岸的水库看守与后来的外围值守有历史连续性；北岸N5二楼的安保生活／技术工作空间，是PDC驻地利用既有办事楼的另一处安排。

48-S休息间与隔壁技术间、50-S换桌核查继续按已设计的N5二楼落位，属于内部人员工作与生活，不因本轮增加东岸安保沿革就迁回东岸。东岸前场值守、接待联络与北岸内部工作可以分别存在，不将其描述成两个重复的庄园总指挥中心。52-SL主楼、58-S酒店的地点继续不变。

东岸安保生活设施随护水源主哨一同建设，用于当班起居、轮班过夜和暴雪留守。收购后北岸承担庄园常规补给和维修，东岸留除雪设备车库与独立应急储备仓，优先抢通对外入口与坝务检修线。设施清单及两岸分工见[交接记录](handover.md)。

冬季保通随运输方式换主次。窄轨经营期，清雪首先保轨道、道岔和换装场，山路只做必要养护。日常补给依靠航运，封冻后接用入冬前储备及庄园自产，北岸是内部补给来源。约1970年改公路后，补给航运退出，公路成为运输和除雪主线。东岸另建公路除雪车库，南岸旧整备场转为铁路主题公园，山路也纳入更积极的养护安排。北岸负责日常补给与车辆维修，东岸保留现场出动和独立留守能力。

## 5. 历史应怎样影响下一步设计

- **旧食堂大空间保留**：38-L员工餐与60-DL晚宴先按同一主厅不同状态排，不另造独立员工餐厅建筑。
- **灶间／厨房长期同源**：旧伙房的位置解释集中厨房；现代收货、储藏、洗消和服务扩建再按分期加入。原炉与烟道是否保留、现代厨房如何扩出，本轮尚未钉坐标。
- **前场与后场各有来历**：员工进餐、私厨预约与食品收货各自能到达，具体是否共用一段通路由平面核对，不先把整组做成酒店后厨。
- **私厨不是别墅家庭餐厅**：20-L仍在别墅西翼小餐厅；这里的预约私厨／宴会业务属于独立食堂建筑组后来的经营用途。
- **外廊是可解释的后改**：60-DL玻璃廊门与厅外谈话空间可来自接待更新，不必硬说是19世纪工棚原有玻璃廊。
- **安保房间与食堂毗邻服务、并非混用**：看守、值守人员来吃饭合理；食堂房间不兼作坝务控制室。食堂、接待／值班及坝务维护三部分可以成组，不要求一栋全包。
