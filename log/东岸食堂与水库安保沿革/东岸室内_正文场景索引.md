# 东岸室内正文场景索引

以下以现行正文为准。正文明确写中央厨房紧邻宴会厅，冬至用餐发生在中央厨房旁的员工餐厅。把员工餐厅与晚宴主厅安排为同一间大厅的两种用途，是现有庄园设定的合并方案。60-DL 晚宴落东岸也是现行空间设定，章节本身未点名东岸。

| 正文章节与段落 | 正文描述 | 对室内设计的约束 |
|---|---|---|
| [27-L：中央厨房开场](../../正文/第一部/27-L_明天的早餐.md#L53)，53–97、167–169 行 | 烤箱预热、洗土豆后沥水、长桌摆面包和水果，另有烘焙区和操作台。储藏间有标签货架和分放肉、蛋、蔬菜的冷藏柜，靠里一段货架后来可放新增干货。 | 洗切、热加工、烘焙、出餐和干冷储藏都要能布置。员工早餐与庄颜借台准备食物同时进行。 |
| [29-L：采购前商量](../../正文/第一部/29-L_你觉得谁说得对.md#L27)，27–53、457–489 行 | 采购清单补食材、锅、菜刀和案板，日常补货仍由主厨安排，私购入库需先商量。 | 这是厨房使用背景，实际柜位见 31-L。 |
| [31-L：中央厨房](../../正文/第一部/31-L_它最近有点奇怪.md#L3)，3–73、539–549 行 | 干货与调味料各占一只柜子，锅和案板放工作台下，带护套的刀入抽屉。门边灯开关旁有嵌墙小屏，声音只在厨房侧响。主厨离开去查看另一间储藏室。傍晚借灶做红烧肉，有洗锅、端盘和摆配菜动作。 | 预留两只专用柜、台下收纳、终端及其本地声区。另一间储藏室要能从厨房工作区到达，具体隔墙位置待定。红烧肉段承接开篇约定，段内没有再次点名中央厨房。 |
| [38-L：冬至包饺子](../../正文/第一部/38-L_窗里的灯.md#L29)，29–85、139–187 行 | 庄颜、罗辑、主厨和坎特陆续上手，大盆馅、多个托盘同时铺开，留有冻存的一批。人从餐厅回厨房煮最后一锅。末尾罗辑看钟和窗玻璃，远处湖面已隐入夜色，玻璃映出亮着灯的厨房。 | 备餐台要能多人共用，托盘能从操作面送到冷冻区，员工厅和厨房之间能短距离往返。厨房窗保留面向湖的视线，墙钟可从室内看见。 |
| [38-L：员工餐厅](../../正文/第一部/38-L_窗里的灯.md#L91)，91–97、135–143 行 | 第一盘端到旁边员工餐厅，坎特分饺子，几人同桌，桌上有醋和小碟。 | 要能拍普通员工围桌用餐和厨房送餐。中间回忆里堆电脑、图纸的长桌属于庄颜过去的场景。 |
| [60-DL：晚宴主厅](../../正文/第一部/60-DL_这张发我一份.md#L3)，3–23、145–183 行 | 多桌宴席，来宾能离席到另一桌交谈和合影。方军给三人拍照时还要把桌上的鱼拍进去。 | 预留桌间走动、上菜、站立合影的空间。正文未给桌数和桌型。 |
| [60-DL：厅外玻璃廊](../../正文/第一部/60-DL_这张发我一份.md#L63)，63–79、145–167 行 | 庄颜带冬马梅走出主厅，廊门合上后厅内声隔玻璃变得模糊。两人隔约两步，庄颜站在回厅的必经处。她们仍能看到厅里的达利兹，最后分别返回。 | 廊门与主厅直接相通，关门后同时保留视线和明显的声场差。门外要有一小段可停步对话的空间。廊的朝向、是否全封闭以及窗外景观留待设计。 |

容易混入的场景包括 20-L 的别墅临湖小餐厅，27-L 回主楼后下面和吃早餐的段落，以及 31-L 从餐厅上楼回书房的餐厅终端场景。39-L 提到中央厨房包的饺子后来送到主楼厨房，可作为跨建筑配餐的旁证。45-D 的中央厨房属于餐饮门店体系，46-S 的食堂属于史强老同事所在单位。60-DL 末段书房发生于次晨。

安保方面，60-DL 只写到来宾对当晚安保尺度的评价。48-S、50-S 的安保生活区、休息间、技术及调查场景按现有设定落北岸 N5。正文检索没有找到可用于定位东岸主哨内室、坝务值班房、除雪车库或应急仓的具体镜头。
