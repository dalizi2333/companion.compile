# 庄园室内参考图清单与空间称谓核对

日期：2026-11-02。状态：正文核对记录及参考图制作计划；非空间定稿，未修改正文。

## 一、制作阶段与用途

当前继续制作正文室内场景的视觉风格参考，不开始正式三维建模。生成图只帮助选择材质、装修、家具、藏品陈设与氛围，不自动确定房间尺寸、门窗位置和建筑布局。后续需从正文整理动线、搭三维模型，再由模型输出一致的正式场景参考。

建筑与环境探索方向为挪威西部Jølster—Førde，主楼气质参考Rosendal、生活与附属建筑层次参考Alvøen，局部木作可研究Damsgård。上述均为设计参考，不代表照搬真实建筑，也未锁定建造年代。

## 二、客厅／起居室核对结果

核对范围：当前 `正文/第一部/` 中相关用词及上下文。

| 章节 | 证据与结论 |
|---|---|
| 01-L | 初见称“他家客厅”，随后称“从起居室到西侧走廊”，返回时“起居室里的茶还温着”，仍使用原茶几。明确是同一房间的两种叫法。 |
| 02-L | “书房比起居室小一些”，承接初见场景；未提供主客厅之外另一间起居室的证据。 |
| 16-L | “东翼二层，书房窗帘”，以及书房“隔壁会客室”；书房与会客室应独立。罗辑另坐在“客厅”，该章未给足楼层和距离关系，不能据听见工程师说话直接把客厅放到二层。 |
| 24-L | “窗边的小起居室”位于罗辑扶庄颜离开楼梯边缘、看见她西翼房门的连续场景中；有沙发、毛毯、茶几水杯、墙上屏幕及通向露台的玻璃门。接近西翼是上下文推断，确切楼层未明。不能仅凭“小”字断言与第一章不是同一间。 |
| 27-L | “回到起居室”看采购清单，尚不能唯一归属主客厅或小起居室。 |
| 38—39-L | 使用“客厅”，有沙发、靠露台的窗、白色纸星、主灯与窗边分组照明、语音终端；与24章有相似要素，但不足以确定同室或异室。 |

**已确认：第一章客厅＝起居室。未确认：24章小起居室是否与主客厅独立；27章归属；38—39章客厅与24章的对应。**

工作建议（尚待用户确认）：视觉规划暂按“主客厅＋西翼小起居室”两间准备，第一章与38—39章用主客厅，24章用小起居室，27章待核动线。两个房间都可有露台出口，但这只是可行方案，不是正文已明确事实。

补正：当前第一部正文检索未找到“壁炉”。壁炉来自原著及既有视觉参考，可选择采用，不能列为本作正文硬约束。

补正（2026-11-02 晚）：用户授权按合理拓扑推进（“怎么合理怎么来”），归属已裁定——24-L「窗边的小起居室」＝西翼独立小起居室（I09，另行出图），27-L「回到起居室」＝主客厅，“两间说”不再待确认。主楼客厅工作平面图（含 01-L／05-L 走位机位与后续章节要求核查）见 [`视觉/庄园与周边/室内参考/主楼客厅布局俯视图`](../../视觉/庄园与周边/室内参考/主楼客厅布局俯视图.md)；另据 38-L「夏天打开可以走到外面」，客厅“靠露台那扇窗”确认为可开启落地窗（文本锚点，非选用项）。
