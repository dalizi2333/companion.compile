# 第十三版：湖岸漫游道与成片果园

2026-11-06。场地 JSON version 13；正文不改。既有别墅、工坊、连续岸线、岩崖和屋顶花园关系保持。只设计固定小哨以东的路径与景观；附楼工作间另行落位。

## 这条路为什么值得慢慢骑

不是沿最短连线赶到别墅，也不是一路贴着陡岸。主路在面湖坡地上顺等高线缓缓转向：桦林收拢视野，草甸打开湖面，石砌停靠处可把车推到一边，经过雨沟、松桦林后再转入别墅庭园。湖侧不连续种高树，保留开阔段与透景窗；坡上树丛提供遮阴和层次。望湖台、坐凳均退出通行带。

模型已改成实际路面，黄色/粉色剧情中心线默认关闭。主路约724.8米、宽3.2米，路肩各约0.4米，细粒压实砂砾面；到宅前转为粗面石板并接有顶签收廊。中心纵坡工作上限5%，最大局部切填约0.985米；道路周边地面一起过渡，不是只把一条路带悬在原坡面上。只在园门附近下车，不用为了沿途台阶频繁推车。

这些尺寸是本轮场景设计参数，并非完整道路施工图。宽度与坡度参考：[Statens vegvesen 维护视角](https://www.vegvesen.no/fag/veg-og-gate/gang--og-sykkelanlegg/planlegging-med-et-driftsperspektiv/)、[N100 2019](https://www.vegvesen.no/globalassets/fag/handboker/n100-veg-og-gateutforming-041219.pdf)。

08-L从别墅反向走共同段，再进入临崖步行支线。支线宽1.5米，非自行车通道。支线全段重新做窄幅整坡，名义纵坡14.5%，与主路衔接的实测局部最大约17.8%；最大切填约0.61米。不能把“主路5%”误写成全支线指标，也不能说08-L骑车抵达长椅。

05-L当天的自行车留在附楼，未骑到别墅。模型到宅前仅设置空车架和停靠湾，不把故事里的那辆车固定放在别墅。附楼后续须补：汽车停靠处、门廊、取伞路径、可将车侧放且不挡人的路边草地、纸夹签收出口。以上是接口要求，不是本轮已完成附楼落位。

## 坡上果园

将原来约20株的小片改为两块成片果园：苹果140株、李子72株，共212株。连草带、边缘和维护通道预留约1.4公顷，树位处自然地面约24.4—40.0米，全部在庄园边界内。果园位于上坡，沿湖主路不绕进去；模型补两片园地周边的割草维护道和小园具棚。

苹果以Prins / Rød Prins、李子以Opal为设定候选，仍沿用第六版树种研究口径。树行有农业管理秩序，湖岸原生树丛则避免排成行道树。果园的面积是本轮空间预留，不是已经测绘登记的历史面积。

历史口径：1970年收购后分批栽种、扩园并整修步道；不倒推为旧工坊时期就有的大型果园。旧石墙可保留，新坐凳、停靠台、林缘整理属于后续庄园景观改造，园具棚的屋檐可承担05-L避雨场景。
