# 地形二维底图导出

更新：2026-11-04。用户希望把渲染结果导成二维纹理，方便据地形修改参考线。本次已实施，未提交/推送 git。

## 交互与输出

左上“导出二维底图”面板：

- 导出 PNG：正俯视、正投影，当前光照，隐藏界面、雾与地名；默认只有地形和湖，可勾选带 3D 预览带及 PNG 参考线。输出 2600×1800。
- 导出描线 SVG：嵌入同一张地形 PNG，另将当前启用类别的参考线作为矢量分层，增加空白描线层。保留总图原有 C/Q 曲线控制点和组位移，不用密集采样替代原曲线。当前 99 条参考路径中 32 条保留原生曲线指令。
- 导出范围与北扩后的总图一致：viewBox="0 -200 1300 900"，每个图上单位 2m，PNG 每单位 2px（约 1m/px）。图上 (0,-200) 对应左上角。无透视/高程横向偏移，可直接在此坐标描线。
- 导出还原当前可见性、相机和渲染器状态，不改变正在编辑的坡线、光照或地图。

SVG 可以在矢量编辑器中修改；当前没有自动导回三维工具的 SVG 导入器。修改后需要把线位回写 `庄园四岸总图.html` 并重新构建。更高像素数不会改变原地形网格的几何精度，岸边小锯齿仍受原网格限制。

## 本地源码与生成物

- `toolchain/scene3d/estate/map-export.mjs`：离屏正投影渲染、可选叠层、PNG/SVG 编码和状态恢复。
- `map-export-layout.mjs`：总图坐标转换、像素行翻转、分层 SVG。
- `extract-reference.py`：为导出保留原始 SVG 子路径和组平移；三维依旧使用采样点贴地，不改变路径坐标。
- `scene-main.mjs`：导出面板、下载入口，光照切换同步导出名称。
- 可重建示例位于工作区 `build/scene3d/exports/`：纯地形 PNG、带预览带和参考线 PNG、描线 SVG、SVG 预览 PNG。均不放入 git。
- 独立 HTML 已重建；预览 `?editor=map-export2&view=map&sun=winterNoon`。

## 验证

- 浏览器实际下载纯地形 PNG、叠层 PNG、保留原曲线的 SVG；两张 PNG 均为 2600×1800，内容有差异；SVG 内嵌地形像素与纯地形 PNG 完全一致，含 99 条可编辑参考路径。
