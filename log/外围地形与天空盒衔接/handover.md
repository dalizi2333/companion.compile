# 外围地形与天空盒衔接

2026-11-10，接续南侧低丘。用户指出地图外围截断、天空盒像绿色墙，需要评估向外补一圈并修正过渡。本记录覆盖上一版约4公里处直接接天空盒的范围安排。

后续用户验收发现北向河谷被外围高地堵住、南侧近景存在不自然接坡，说明本次雾化与日照检查不足以证明地形合理。当前修正以[北向河谷与南部接坡修正](../北向河谷与南部接坡修正/handover.md)为准；下面的截图判断及顶点统计只描述当时版本。

## 设计与实现

保留现有精细场地，在旧实体矩形外新增独立的低精度地形环。`toolchain/scene3d/estate/outer-terrain.mjs`根据旧mesh实际边缘的1,284个节点生成16层渐疏网格，新增20,544顶点、38,520三角形。新范围E约−19.9至20.1公里、N约−19.7至19.8公里；原核心网格、田路、建筑、裸岩与树林不改变。

外围按宽脊、浅谷及南向低丘塑形，不直接外推旧Bézier坡。内接缝逐点保留原高度、颜色和法线，接缝高度误差0。沿边界150米范围平滑坡度和颜色，原始细节在450米内消退，避免把每个细节点的坡度放大成数百米的放射状长沟。`groundAt`读取实际环带三角面，供日照检查使用；旧矩形内部和外围范围以外返回NaN。

`mountain-sky.mjs`删除原南向三层平行色带及无限向下铺展的绿色山色，只保留低对比远山剪影，地平线以下渐隐到雾色。Three r187的Fog在色调映射与输出转换之后混合，因此天空关闭ACES（`toneMapped=false`），haze uniform使用线性雾色，经正常sRGB输出后与地形完全雾化的颜色匹配。

雾从2.6公里开始，前向深度12.5公里处完全融入雾色；相机远裁剪面40公里。高鸟瞰、南西、南东、北向及庭院视点分别检查可见外边界的相机前向深度，不能仅用世界径向距离代替。外围末端应在完全雾化区内，避免把矩形截边换到更远处。

这是视觉远景环，未延长精细道路、河道或实例森林，也不作为新的可游览场地。原2D底图坐标及坡线编辑范围保持。

## 冬至约束

南向天空天际线沿用约0.49–1.19°，正南约0.86°。外围南坡以既有边界遮挡角及天空天际线约束高度，保持低谷开口。`inspect-winter-sun.mjs`不再受旧5.5公里上限截断，改用场景30公里上限，到实际地形边界停止；近处仍0.5/2/8/20米步长，5.5公里后100米、15公里后200米。

沿用48个实际接收点及8批计算。角度、地点、保守树冠、建筑和室内范围限制仍见[南侧初版记录](../南侧低丘与冬至日照/handover.md)。最终差异及校验数据保存在下列输出目录。

最终复核：48点全部太阳采样的直射/遮挡结果与上一版一致，未缩短主楼及庭院日照。各射线实际采样到20.204–24.204公里，全部到达外围边界的最后一个200米步长以内，没有因中间NaN空隙提前停止。主入口仍10:49–14:14 CET，庭园中心地面仍11:04–14:04；花灌木和旧厕屋的既有局部阴影保留。

六个视点的边界检查通过：可见外边界最短前向深度约13.782公里，大于12.5公里完全雾化距离；高俯视视锥内无外边界。修正后的各方向截图未见原绿色墙、平行色带或放射状长沟。浏览器无JS/着色器错误，HTML与当前源代码构建一致；保留设定的五份JSON校验值不变。汇总为`build/外围地形与天空盒衔接/最终校验摘要.json`。

## 复现与产物

主输出仍是`视觉/庄园与周边/庄园三维体量模型_v3.html`，刷新后可用“南向低丘全景”“庭院向南望”“北岸后山全景”等既有按钮。

```bash
npm --prefix toolchain/scene3d test
node toolchain/scene3d/estate/build.mjs
node toolchain/scene3d/estate/verify-south-uplands.mjs --outer --out build/外围地形与天空盒衔接
```

加`--visual-only`仅检查和导出画面，不重跑太阳路径。外围不加入默认2米等高线层，以免远处轮廓和标注过密。

`build/外围地形与天空盒衔接/`包含修改前文件、各方向截图、模型几何检查、远边界雾化检查、冬至复核及分批明细。代码测试为50项JavaScript与3项Python；浏览器检查包含着色器错误、实际灯光角度及日照。本文为历史阶段记录，当前出口和接坡以文首链接的最终修正为准。
