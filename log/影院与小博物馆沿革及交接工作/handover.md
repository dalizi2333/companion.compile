# 影院、小博物馆、通信沿革与庄颜交接工作

2026-11-05。用户授权记录本轮讨论，并仅在“草台班子 · 主楼拓扑”补小胶片收藏室和定制空调系统设备间。**正文不改；别墅小博物馆详细布局尚未设计。**

## 已采纳的关系与年代工作值

以下为虚构庄园的创作年表，技术史只验证可行区间，不证明庄园曾有这些设施。具体安装年、历代屋主身份尚未锁死。

| 时段 | 改造与用途 |
|---|---|
| 1880年代后期，早于西翼 | 先装庄园内部电话，连接主楼、北岸账房/管事办公处和主要服务用房；主人可打电话召管家、直接交代任务。内部专线不以公共电话接入为先决条件，对外电话接入年份取决于当地线路。 |
| 1890年代西翼扩建 | 已有电话延伸至管家房、备勤处和能源机房；白天接听点以备勤处为主，不把每次召唤都打进卧室。机械拉铃/后来的电铃可与电话并存。电话不是修西翼后才出现。 |
| 19世纪末—20世纪初，细年待定 | 北岸账房/运输值班附近可有小电报室，服务订单、货运、航运接驳和账款。最初递送电报与真正装机接线分开；接入外部线路须有正式安排，窄轨存在不自动等于拥有铁路电报。不是私人无线电台。 |
| 1920—1930年代 | 家族开始积累家庭、旅行影像和放映设备，改造西翼梯形家庭起居室，在南面挂幕布；尚不要求专门影院，早期以16毫米等安全片方向为宜，不默认35毫米硝酸片收藏。 |
| 1960—1968年，初建候选区间 | 下一代发现童年家庭影像在早期长期偏暖的储存环境中已经褪色、损伤，决定向西扩建沿坡家庭放映厅，附正式小胶片收藏室、放映设备和定制通风/温湿度控制。厅堂服务全家及少量客人，中段应有阶梯多排座席，后排连续沙发保留两人正文走位；具体改图未完成。 |
| 1970年代以后 | 别墅逐步改作小博物馆，更多收藏分批转入；家庭历史原件与泛类收藏区别对待，不默认主楼独一无二的原片全部迁走。屋主持续改造，使其兼具展陈、专用片库、档案、馆务和后来的数字化工作；主楼小片库逐步转为周转片库/检片用途。并非一次搬空主楼，也不把所有原件放进普通展室。 |
| 1980—1990年代前期 | 先把部分家庭胶片转录为录像带方便观看；“电子版”在此阶段不等于电脑文件。影院保留胶片与电子播放并存的改造痕迹。 |
| 1998—2006年前后 | 重要影像分批委托专业机构数字扫描，博物馆建立数字目录、存储与播放服务，配套专用小型服务器机房及全庄园光纤骨干。千兆骨干符合时代；万兆仅作为后期核心存储升级候选，不默认全宅起步万兆，也不将内网速度等同外网带宽。 |

**覆盖旧年代口径：** 历史母设定原“1995—2006主楼内增设现代放映功能”今后应理解为数字化/现代化升级，不能再据此认定影院建筑当时才初建。本轮按用户范围仅在log留覆盖说明，母设定年表待后续统一整理。

## 小博物馆、数据中心与主楼分工

- 数据中心在**别墅小博物馆**：独立服务器机房，服务藏品目录、扫描文件、数字影片、备份和后续庄园管理。它是历代追加的馆务设施，不是单一展厅里堆服务器；规模、位置、结构与散热尚未设计。
- 主楼仅设**小型弱电柜**，含光纤接入、交换机、配线和小型后备电源；影院可保留本地播放端和缓存，不在主楼新增数据中心。
- 原胶片不会因数字化而销毁；原件、保存母版、日常观看版各有用途。展示区、低温片库、数字化整备间、服务器机房需要分别考虑环境。
- 现阶段不擅自设定庄园自建完整专业胶片扫描实验室；重要扫描可委外，馆内承担检查、编目、资料整理及数字成果管理。
- 博物馆兼有馆务与访客住宿：别墅西翼资料归档室、客房、小起居室和露台仍成立。24-L发生于客房区，不需搬到主楼；01/02-L画作和书房仍在主楼。
- 民用/馆务网络与PDC安保、保密通信、人事审批分域；既有光纤和服务器不使私人Agent自动获得PDC权限。

## 空调与片库：本轮总图实施

影院扩建可成为全宅定制空调逐步改造的起因，但不是一个年代一次性装完所有设备。原水暖继续负责主要采暖；舒适空调、新风与片库低温控湿分别设计。藏片与观众厅/热设备不共回风，机组需隔振消声；室外换热端、冷量、风管与检修净空未选型。

**后续用户修订已实施：撤销本轮最初的“北侧−1层”方案，配套移到影院南侧、高台后方的1层。** 原有57间房编号不变；本轮新增两间改归1层，旧B1-18/19轮廓撤下，不继续当有效房间。

- **定制空调设备间**：u=-27.4..-24、v=9.2..12.2；刚性米制墙线约3.40×2.95m、10.05㎡，南门独立检修。
- **小胶片收藏室／放映整备**：u=-24..-18.4、v=9.2..12.2；刚性米制墙线约5.60×2.95m、16.55㎡。南侧1.10m接收门让博物馆调出的胶片直接进入受控接收环境，不先经过观众厅；北侧1.10m内门联系观影门斗，并预留朝影院的操作/观察窗，使本室可以操作放映设备。
- 受控藏片、回温/检片整备和发热设备操作区需内部分隔，尚未细排；“直接进入收藏室环境”不等于把未经回温的冷胶片立即拆盒放映，亦不把热投影机和低温片柜混在同一环境。
- 两间南门各自面向室外收货/检修坪；机房不成为运片必经之路。影院后墙同步留出收藏室内门，不保留挡住通路的整段实墙。
- 生成器v不是物理米数，尺寸以导出JSON为准。空间为设备占位，最终机组、藏量、隔断、投影光路、风管、隔声与地形仍待细化；不认定可存硝酸片。

### 扩建动机：童年影像损伤

1920—1930年代先把梯形家庭起居室改作家庭放映用途，幕布挂南面。初期把放映与藏片附属于暖房生活，邻近锅炉系统的旧暖环境及储存条件不适合长期保存胶片。到下一代回看时，童年影像已有褪色、失真或片基老化，遂决定正经修收藏室、配独立环境控制，并另建家庭影院。这是长期不合适的温湿度/保管造成的劣化，不写成锅炉自动把全宅加热到危险温度，也不保证所有胶片都能修复，更不是人物记忆本身模糊。

主楼保存的家庭影片、独有照片及相关历史原件，对前家主尤其重要：它们是家人和庄园自身留下的唯一记录，失去后无法购买另一件替代。小博物馆也存大量收藏，但“主楼中的家庭历史收藏”是前家主对本次盘点最不肯随便的一部分。胶片可根据保存状况在博物馆长期库与主楼受控收藏室之间调取，精确逐件存放清单尚未定。

## 前家主要求盘点与庄颜工作

**本次正式盘点/交接源于前家主的明确要求，可作为移交条件，由馆务人员落实，PDC组织接管与使用确认。** 前家主有长期收藏、考订、归档和维护习惯，重视物品位置、版本和交接记录；尤其认真对待主楼独一无二的家庭历史原件，既有童年影像曾受损的经历，更不能接受含糊移交。罗辑没有同样的私人收藏习惯；他可以欣赏、使用某件东西，但不主动持续搜集与经营整套收藏。

庄颜的临时岗位：**庄园接管项目的中文资料核对助理**，不是接替馆长、从零重编全馆目录，也不承担藏品修复、鉴定或机房维护。

工作包括中文检索名与原文对应、书籍/陈设实物编号与位置核对、字幕和片源版本的使用确认、交接核验记录整理。她在小博物馆可有临时工位，同时须到主楼核对现场、取使用者答复，到附楼工作间领取核验材料，再回别墅归档。05-L现有纸质材料可理解为本次交接形成的带更正/签认核验表，不因既有电子目录而失去作用；不新增涉密属性，不需修改正文解释。

**01-L小彩蛋保留隐含：** 罗辑一直以为前主人的收藏都在小博物馆，对主楼仍有收藏和交接人员来访没有兴趣。他原想全部让人自行决定，抬头看见庄颜后才突然关心版本、题名和原画。画《有人在等》仍在主楼西侧走廊，02-L随后进入自己的书房不改地点。无需强调是否“馆藏”，不加科普式交代，不把此前建议的馆藏解释台词补进正文。

这份清单认真，是前家主认真；罗辑突然认真，是因为庄颜。该差别留背景，不强行由角色说破。

## 后续覆盖：放映机房实隔间与全宅空调（2026-11-05）

用户要求观众厅内看不到投影设备，已实施L1-34独立放映机房，由L1-33收藏/整备室进入，隔墙留放映窗；热设备环境与胶片储存分别控制。原L1-33向南加深并改L形，旧约16.55㎡矩形描述不再适用，当前精确面积/门洞见新轮廓JSON。首版单间俯视图未重绘，不再代表投影设备位置。

全楼空调按“当时有技术即可定制”的用户口径研究，不以市场主流为先决条件。1960年代冷冻水＋局部末端可作为方向，现代VRV不能倒填；全宅路由尚为工作方案，没有把所有房间改成全空气大风管。阁楼、走廊检修吊顶、湿区管井与局部柜式末端的分区方案见[空调改造分区与放映机房](../../视觉/庄园与周边/室内参考/主楼草台班子_定稿/空调改造分区与放映机房.md)。北侧大餐厅只在凸出上层轮廓部分具备独立屋顶条件，南段上方仍有东翼上层。

## 已定稿：静音优先级与机房扩长

2026-11-05用户确认。全宅以就地末端制冷为默认，不默认布置全宅制冷风管；家主愿意先投入定制静音末端，普通房间可接受噪声即采用。老人房及卧室按最高静音等级考虑，无法满足则风机移至房外检修位置，用局部短风管/消声，不以牺牲夜间舒适换静音；影院同理。片库、投影机房分别按保存和散热需要处理。采暖水暖保留，新风排风另行安排。

空调设备间向南延长，与收藏室外包络南墙对齐：约3.40×4.43m、15.07㎡；南门和检修支路同步南移，片库L形及独立放映机房保留。此前设备间约10.05㎡、南墙v12.2的描述已过时。全宅分区原则定稿，管线、设备型号、负荷与噪声数值尚未设计；正文不改，影院多排座席另待改图。
