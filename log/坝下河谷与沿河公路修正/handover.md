# 坝下河谷与沿河公路修正

> 本文记录本阶段实施与当时验收。完整场景已接续后续修正，当前入口见[三维地形与地表说明](../../视觉/庄园与周边/三维地形与地表说明.md)。

2026-11-10。用户指出坝下公路在低处之后重新爬上山包，旁侧洼地甚至低于河面；按标图将下游公路收向沿河低坡走廊，并修正地形。

## 原因与修改

- 原 `downstream-valley.mjs` 用有正负值的正弦起伏直接加到谷地，实测东岸 E1223.78/N2260 地面约 −27.14m，同段河面约 −3.73m。公路逐点贴地，之后又升到约 +26m。
- 山肩改为平滑的正向起伏，河床仍低于水面，岸地从河边向外抬升。湖面零点、现有坝体和原八条坡线保持。
- 保留入口弯道，下游逐渐收至东侧河岸外约38m，按独立纵断面连续下降。设置路肩及切填，直接细分主地形网格，避免道路仅悬浮覆盖在原坡上。
- 生成源：本地 `toolchain/scene3d/estate/downstream-valley.mjs`、`downstream-road-mesh.mjs`；总场景仍为 `视觉/庄园与周边/庄园三维体量模型_v3.html`。

## 验证与状态

- 22项 JavaScript、3项 Python 测试通过，包含新增的两岸干地高于河面、道路连续下降与全路幅岸线退距检查。
- 当前存档地形的道路全幅抽样1437点，路面比实际细网格高0.1786—0.1811m，无穿地或缺面；最大下坡约5.681%，不作为道路规范验收结论。
- 原洼地最低样点修正后为+14.43m，同段河面−3.73m。原八条坡线、坝桥线位JSON和四岸总图的文件校验值保持。
- 细分网格295387顶点、557828三角形；索引和坐标有效，不改参数再次刷新最大坐标差为0。数值报告：工作区 `build/坝下河谷_几何复核.json`。
- 8734服务返回200，当前页面无运行错误。实际道路479个断面连续下降，路宽5.6m；路缘距东侧岸线的E向差最小约33.36m。抽查主地形干地顶点（距岸15—500m）高于同段水面至少1.41m。
- 已检查普通视图和等高线叠加视图。截图与页面复核报告在工作区 `build/坝下河谷修正/沿河公路_回望.png`、`沿河公路_等高线.png`、`浏览器复核.json`；浏览器验证脚本为本地 `toolchain/scene3d/estate/verify-downstream-valley.mjs`。道路与河谷仍为庄园场景体量设计。
