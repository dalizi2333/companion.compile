# 北岸后山地形重塑

> 本文记录本阶段实施与当时验收。完整场景已接续后续修正，当前入口见[三维地形与地表说明](../../视觉/庄园与周边/三维地形与地表说明.md)。

更新：2026-11-10。按用户在生图方案上的最新标注，先修改总模型的真实地形。红线外为天空盒远景；棕圈是原来平坦的北端台地；蓝圈为西南侧斜向山肩，可依现地重塑。

## 已实施

- 仓库新增 `视觉/庄园与周边/北岸后山地形.json`。记录前缘保护线及坡脚高程、坡肩展开距离、7条山脊/支脊、4道浅谷。单位为米，坐标为 E/N，湖面为0。
- 棕圈北端台地改为后方圆缓主脊、前方支脊和中间敞开的浅谷。原有250米与200米平台交界统一过渡，取消硬台阶。
- 蓝圈侧坡改为从主脊向西南延伸的山肩。中间高坡也采用连续坡脚—坡肩断面，减少旧坡线达到最高值后突然转为平顶的折痕。低处梯田、牧坡、果园及道路保持原有布局和标高控制。
- 在原地形网格上修改高度，不新增延伸到远景的实体山体。红线是单张透视图上的意向边界，按既有网格后缘与主脊对应，而非逐像素反投影的精确测绘线。
- `mountain-sky.mjs` 在原天空球上绘制西北方向的三层远山；北向河谷口保留低鞍部。此层仅是当前体量预览用的程序化背景，没有地面或碰撞面，还不是照片级天空纹理。
- 页面增加“北岸后山全景”和“后山地形俯视”。查询参数分别为 `?focus=north-mountains&contours=0`、`?focus=north-mountains-top&contours=1`；固定机位为 `cam=NM` / `cam=NMT`。

## 工具链入口

本地 `toolchain/scene3d/estate/north-mountain-core.mjs` 负责保护范围、连续山肩断面及脊谷细化，`north-mountains.mjs` 读取仓库JSON；`scene.mjs` 接入基础高度场，`north-landform.mjs` 在新区域淡出旧的峰包与染色，保留农业及牧坡细化。`scene-main.mjs` 接入查看入口。

构建：`node toolchain/scene3d/estate/build.mjs`。

## 验证

- 26项 JavaScript 测试和3项 Python 测试通过。新增检查覆盖湖岸、牧坡、梯田控制点、坝下河岸、公路走廊、山体前缘连续性与脊谷高差。
- `node toolchain/scene3d/estate/check-north-mountains.mjs` 检查实际基础网格：295,387个顶点、557,828个三角形，重新刷新后顶点最大差为0；位置和法向均为有限数。
- 棕圈检查矩形 E=-1450～300、N=2400～3280 内，含原坡脚的高程约165.95～311.83米。最高采样点 E=-1310/N=2990。蓝圈山肩控制点 E=-1080/N=580 约274.86米。以上是虚构场景相对湖面的设计值。
- `庄园坡线.json`、`庄园四岸总图.html`、北岸院落场地JSON、既有坝下山林JSON的校验值均保持不变。
- 浏览器截图和数值检查存于本地 `build/北岸山体重塑/`；修改前HTML也在该目录，可回看同机位。几何报告为 `地形几何复核.json`。
- 最终浏览器实际场景已检查全景和俯视等高线。主地形经院落/岩台等局部面替换后有483,465个三角形，位置/法向有效；5948棵既有坝下树木最大树根贴地误差约0.000119米；坝下公路相邻下游采样点最大升幅为−0.001955米，仍连续下降。天空盒为独立SphereGeometry且不参与等高线。报告为 `浏览器复核.json`。
- 8734服务返回200，页面内联脚本与当前工具链重新打包结果完全一致。未观察到页面脚本错误。
