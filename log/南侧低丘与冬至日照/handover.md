2026-11-10。按用户批准的南向概念落实地形、地表和远景，复核主楼与庭园的冬至直射日照。当前为Three.js场地模型，不是实测地块或Blender精细资产。

## 地形、地表与远景

真东E、真北N，真南为N减小，高度相对湖面。主楼落位E62.771/N666.095/Y5.6保持。`视觉/庄园与周边/南向低丘地形.json`将原南侧高平台改为中央宽谷、错落低丘和两侧缓脊。正南保留采光走廊，西南旧牧坡保持，所以仍会遮挡下午的低角度阳光。新高度场保护既有主楼庭园、湖岸、北岸岩林和牧坡。

实体南边界N−3205，距主楼正南约3.87公里，侧向E−3404至3604，主要南向视域的实体覆盖约3.5–5公里。外围接低山天空盒，南向天际线约0.5–1.2°，也纳入日照检查。天空盒按无限远方向绘制，不随相机平移漂移；高鸟瞰仍可区分实体与背景，其用途是体量预览。

原257²网格前缀及既有细分保留，南侧附加15.23米网格；两侧北部空缺用约122米粗网格封口至原北界N3300，消除截边投影出的尖楔。全部接缝共用顶点，刷新幂等。最终主地形391,326顶点、675,083三角形（扣除已被局部场地替换的旧面）。

`南向低丘地表.json`包含12片疏林、14片低露岩。实际生成5,752株树：桦3,947、松1,503、少量云杉302；林下灌木1,351丛、低荒草/石楠4,131簇。高树集中两侧避风凹地，新增高树进入预留采光走廊数量为0。岩面随实际地表贴坡，边缘渐退，并留草地、矮灌过渡。原坡线、主楼落位、南岸接线、北岸地形和林岩JSON的校验值均保持。

## 冬至结果

地域设计假定61.5°N、6°E，2026-12-21，当地冬季时间CET（UTC+1）。太阳正午约12:34，高度5.06°。太阳位置依据[NOAA公式](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)，以冬至赤纬−23.44°计算太阳中心，5分钟采样。

| 接收位置 | 可直射时段／结果 |
|---|---|
| 主入口南立面 | 10:49–14:14，约205分钟 |
| 首层私人浴室南立面 | 10:34–14:19，约225分钟 |
| 二层家庭厅南立面 | 10:29–14:24，约235分钟 |
| 西翼现有南窗外、东翼门斗南立面 | 均10:34–14:19，约225分钟 |
| 南主门外地面 | 10:49–14:14，约205分钟 |
| 庭园15个地面点 | 均有直射时段；正午12/15点晒到，累计25–200分钟 |
| 同15点的1.2米高度 | 正午15/15点晒到，累计185–210分钟 |
| 前院5个地面点 | 正午4/5点晒到；老厕屋后方点中午被遮，分上午、下午两段共95分钟 |
| 临湖北立面对照 | 冬至不朝向太阳，0分钟 |

正午没晒到的3个庭园地面点均为E38一列，由2.8–6.5米外既有花灌木与宿根花卉遮挡，并非南山过高。庭园中心地面约11:04–14:04，约180分钟。主入口正南地形遮挡角约1.33°，远景约0.86°，相对正午太阳余量约3.73°。

当前满足“冬至主楼南向位置和庭院能晒到太阳”，不代表整个庭园地面同时无阴影。未为测试通过移动老厕屋或删掉花灌木。

## 方法与限制

48个接收点：庭园15点、前院5点、门外1点，各取贴地0.05米与1.2米；另有5个南向立面点和1个北立面对照。起点使用实际成形地面或铺装，主门点在入口标记薄板外，避免把铺装内部当作接收点。

实际网格按距离以0.5/2/8/20米步长采样，最大5.5公里，到实体边界停止；建筑和凸起岩面以实际双面三角形射线检查，实例树冠用不透光包围盒保守计算；天空盒角高度与着色器一致。约67万次地形采样，保守筛选后3,205个遮挡候选。分8批运行控制内存，随机冠体测试验证剪枝与未筛选射线结果一致。

时段端点约有5分钟采样不确定性。未计云、降水、积雪、折射和落叶后的透光率；未做室内窗洞、玻璃与房间进深的穿窗模拟，立面受光不等于室内日照时长。太阳灯已修正为相对light target计算实际方向，冬至预设由旧5.6°改为5.06°，旧北岸粗核历史记录不覆盖本版。

主输出：`视觉/庄园与周边/庄园三维体量模型_v3.html`。

- `?focus=south-uplands&contours=0`：南向低丘全景（SM）。
- `?focus=south-uplands-top&contours=1`：俯视与等高线（SMT）。
- `?focus=south-garden-view&contours=0`：庭院向南（SG），可点“冬至正午”。
- `?focus=winter-house&contours=0`：主楼庭园近看并自动切冬至正午（SH）。

```bash
npm --prefix toolchain/scene3d test
node toolchain/scene3d/estate/build.mjs
node toolchain/scene3d/estate/verify-south-uplands.mjs
python3 toolchain/scene3d/estate/plot-winter-sun.py
```
