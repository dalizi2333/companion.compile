# 视觉 —— 角色、道具与场景设定

视觉形象素材的工作目录：**图像与描述文本同名成对**（`主视觉.png` / `主视觉.md`），一个角色一个子目录。

场景目录同时保存空间设定、JSON、HTML 与三维资产；庄园当前入口为[三维地形与地表说明](庄园与周边/三维地形与地表说明.md)，按角色图像成对的规则不限制这些场景数据。

剧情关键道具放入**所属角色目录**（如罗辑的手机随 `罗辑/`），跨角色的品牌级资产（星米 logo）单独建目录；记录跨章节外观和状态连续性，道具设定图确认后与描述文件一并入库。

## 结构

```
视觉/<角色>/
├── 主视觉.md / 主视觉.png      # 基准形象（面部、发型、体型、默认服装、配色板、一致性锚点）
├── 章节/                       # 章节变种：只记录与主视觉的“差异”
│   ├── 第01章.md / 第01章.png
│   └── …
└── <角色个人关键道具>           # 如罗辑手机：罗辑手机-背面/-正面/-旧机正面/-旧机背面（svg+jpg）+ 罗辑手机.md
视觉/星米logo/                    # 品牌级标识资产（集团本牌，独立于角色，一稿全仓复用）
```

## 规则

1. **变种只记差异**：章节文件只写该章相对主视觉的变化（服装、发型、伤痕、季节、年龄感），未提及项一律沿用主视觉——保证全篇一致性有单一锚点。
2. **命名**：变种按章号零填充（`第01章`、`第60章`）；同一形象跨越多章时可用区间名（如 `第01-05章`）或时期名（如 `庄园期`），以先到者为准。
3. **定稿图入仓，过程稿不入**：GPT 生成→作者定稿后，成图与最终描述文本一起入库；中间迭代留在本地工作区。图像暂走普通 git，单文件超限或总量失控时再议 git-lfs。
4. **图像两级分级**：入库图长边 ≤2560px（查看器与远程预览友好）；高清原图存同级 `原图/` 子目录——本地保留、git 忽略（`.gitignore` 规则 `原图/`），推远程的只有入库版。分级脚本 `toolchain/image_tier.py`（根目录本地驻留）。
5. **许可**：跟随仓库双轨——原作人物（罗辑/庄颜/史强）的视觉为衍生表达，原创人物（达利兹/沈知衡/顾承钧/克罗得）的视觉在 CC BY-NC-SA 覆盖内，见 `LICENSE.md`。
