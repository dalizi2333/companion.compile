# 罗辑浴室布局俯视图

2026-11-06。L1-10，首版。

- 原型是1850年代普通附属房间，具体原用途不锁死；保留3.40×2.90m矩形、原门位、常规南窗及干区木作。不是原建就按浴缸、湿区和排水井组织的浴室。

- 1890年代热水工程把浴缸、盥洗设备装进现成房间：浴缸沿东侧后置，普通家具比例的木柜改盥洗台；房间西半仍能放布草柜与更衣椅。南窗、窗台和干区踢脚线保留，不把四面墙全铺现代瓷砖。

- 东侧浴缸周边后来更换地面基层、防水与低位硬质护面，干湿材料交界设齐平收边，不人为砌出跨越台阶。保留老木作外观不表示旧木地板直接承担泡水或浴缸荷载；防水/承重须另核。

- 后加冷热水沿东墙可检修包箱与柜后进入，浴缸排水由东南角进入新增检修立管/室外合适管路方向，接点和坡度待核；不能钻进主楼下方当作可用地下室，也不默认接已取消的WC。盥洗台支管沿南墙脚绕行，包箱是后改痕迹。

- 42-L毛巾动作：罗辑靠浴缸北端坐、面朝南，他的左边是东墙T01毛巾杆；毛巾原本就在伸手一侧。庄颜从北门进来，可沿浴缸西侧接近，不必跨浴缸或踩设备。此坐向是设计选择，正文未规定他一定在泡澡。

- 冬季靠全屋水暖H7维持温暖。E01为后加辐射补热器，供夏季/换季停采暖时短时使用；不采用有噪声的强吹风，不让现代集成浴霸决定原房间布局。具体型号/安装分区、电路和安全距离未定。

- 盥洗台镜面在西墙，高位补热与镜柜错开；照明用独立实体开关，无须新增Agent小屏来解释42-L喊语音助手。原照明/水暖早于05-L新家庭中控，断Agent仍可洗浴。

- 本室无马桶，不增厕所；门洞沿总图，西铰链向内开为本轮试排。南窗组合1.20m为普通旧窗占位，砌口/窗台高度待核，不按现代落地淋浴窗重开墙。
