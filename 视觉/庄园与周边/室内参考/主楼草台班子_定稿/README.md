## 本版要点

- 南高北低，主楼北侧临湖；中央主体下方为实心地基，西翼设备间收短不侵入。
- 主客厅南门直通门厅；卧室和书房同层，经更衣连接间相接。卧室不直通客厅。
- 西翼整体内折约10°，内部规整矩形；只有家庭起居室梯形贴回主体。一条走廊连接南侧短过厅、主人房间和佣人房间。
- 老人房与家庭起居室不开直通门，走廊对面是私用浴室。主佣按自用生活范围区分，佣人照常给主人服务，不设硬隔断。
- 坎特一间；女仆房两间，1层和北侧露明−1层各一间。
- 车库是后期堵在旧佣人入口前的两车位扩建；影院后加在西端。主人取车、观影反向进入佣人生活区，无新增主人长廊或观影棚架。
- 影院连续跨层，1层放投影设备与观影平台，幕布下探−1层；低台维护门接库房。
- 东翼下层按南—中—北：埋土地窖，中段西厨房/东杂物，北侧大餐厅。主人从西端B梯沿短廊入餐厅。
- 西翼后勤步道接餐厅西北外门，再进厨房；东侧旧平院保留平进平出，另期东扩收货间、高差卸货边和皮卡棚。

## 本地复现

生成工具位于工作区本地 `toolchain/scene3d/house/`，不进源码仓。依次运行：

```bash
node toolchain/scene3d/house/build.mjs
python3 toolchain/scene3d/house/export_rooms.py
node toolchain/scene3d/house/render-atlas.mjs
```

依赖复用 `toolchain/scene3d/node_modules` 中的 three、esbuild、puppeteer-core 和本机 Chromium；无新增安装。固定资产已完整入本目录，下一位 Agent 不需要生成工具也能开始改单间。
