# 空调改造分区与放映机房

2026-11-05，本轮设计工作方案；正文不改。机房隔间已落实粗模，以下全宅管线路由是候选，不是已验证的施工图。阁楼、冷冻水/风管/排水管尚未建模。

## 判据与年代

用户明确：本家愿意定制，优先判断技术当时是否存在，不受挪威普通住宅习惯或市售成套机限制。1960年代可研究中央制冷机＋冷冻水输送＋局部空气处理/风机盘管，原水暖继续采暖；影院、片库和住宅各自空气循环，不把全宅空气统一送进一间机房。

冷媒多联机VRV1982年日本推出、1980年代后期进入欧洲；不能倒填1960年代。此前已有制冷剂直膨设备，但不因此认定现代变容量多联机当时已存在。1990—2000年代可换机组与末端、加数字控制，旧主干路由可保留。定制能力不意味着忽略换热、除湿、排水和维护条件。

技术参照：[Carrier制冷史](https://www.carrier.com/us/en/history/invention-of-air-conditioning/)记1922离心冷水机；[Trane历史](https://www.trane.com/commercial/north-america/us/en/about-us/newsroom/blogs/reuben-trane-invention.html)记1931年已有冷水盘管、风机与冷凝水盘组合，证明该技术组合早于1960年代，不规定本宅使用该品牌/巨型离心机。[大金VRV史](https://www.daikin.com/air/daikin_achievements/innovation/modals/08_1982)界定现代多联机年代。挪威当时各类空调市占/住宅习惯未查实，不作主流断言。

## 已实施：影院后部独立放映机房

南侧原收藏/整备空间向南加深约1.48m，在其西北角隔出独立机房：

- L1-32定制空调设备间保留独立南门；与胶片、投影设备不混为一间。
- L1-33小胶片收藏室／放映整备改为L形，南门接收胶片，北门进观影门斗；另有0.90m内门进入机房。藏片及回温整备内部分隔仍待细化。
- L1-34独立放映机房约3.00×2.46m，单机及检修空间须按实际设备复核；不默认够放双35毫米机。仅从收藏/整备侧出入，不向观众席开操作门。
- 裸露吊装投影机已从观众厅移入机房；机房朝厅隔墙按完整高度表示，仅留约0.90×0.55m暗色放映窗。观众可能看到镜头光，不应直接看见整台机器。光学玻璃、窗口光轴与镜头投射比尚未选定。
- 机房散热/补风、片库存储温湿度、观众厅舒适环境分别控制，不串联回风；片库不是机房的补风来源。实际排风口、室外换热端和容量待设计。
- 第一版《放映室布局俯视图》仍画厅内投影机/单排沙发，已被本轮拓扑口径覆盖，不能据此回退机房或全家多排座席方向。该详细家具图后续整体重画。

## 全宅路由候选

建议“冷冻水干管＋分区末端＋独立新风”，并非全宅大风管；新风管也不能因有风机盘管而省略。风管型末端和冷媒/冷水输送不是互斥分类，水盘管/冷媒室内机都可以接短风管。

| 区域 | 可用路由及末端候选 |
|---|---|
| 西翼1层、东翼上层、主楼2层 | 各自屋顶/阁楼设可检修空气处理或短风管末端，保温管沿服务管井送到各区；不同翼不假设阁楼贯通。具体屋架高度、通道承重和检修空间未定。 |
| 北侧大餐厅 | 只有超出东翼上层轮廓的北侧部分可新设独立屋顶服务空间；仍压在书房/会客室下的南段不能称阁楼。可利用北段机组/短风管沿厅周边送风，或局部吊顶。 |
| 主客厅、罗辑卧室 | 上有二楼，不能从阁楼直接落大风管穿卧室。利用主门厅、南侧短过厅、私人走廊/小过厅的局部检修吊顶或柜顶，安分区末端，短段接到房间；必要时窗边/墙边检修柜装盘管。具体优先位须和门扇、柜体、烟囱及卧室折入动线联核，未钉死。 |
| 主楼纵向联系 | 优先新增在湿区/后勤侧的检修管井，与原烟道隔开；不直接占活烟道，不在木梁上随意钻大洞。冷冻水管保温后并非无尺寸，冷凝水也需路线。 |
| 西翼−1层 | 家务前厅顶/墙边设局部管带，短支路入值守卧室、库房；不挖主楼基础当全宅送风地道。 |
| 东翼−1层其他房间 | 沿后侧服务短廊顶与墙边分配；厨房、卫生间和洗衣作业区的污染/潮气排风独立，不回入片库或卧室。 |

原地暖/散热器采暖系统保留，不把老采暖管直接通冷水当制冷地板。冷凝水优先重力排至合适排水点，避免长期依赖藏在卧室内的水泵；所有冷表面需隔汽保温。阁楼可用不等于冷风管能裸放在冷阁楼，仍需保温、密封、防结露并保留屋顶通风与检修。

以上是结合当前拓扑的设计推演。参考[Historic England旧建筑机电安装](https://historicengland.org.uk/advice/technical-advice/building-services-engineering/installing-new-services/)对可检修路由、原有开口的原则，及[美国能源部风管保温说明](https://bsesc.energy.gov/energy-basics/hvac-sealed-and-insulated-metal-ducts)对非空调空间风管结露控制的说明；这些不是挪威法规证明。负荷、管径、机房和末端净空、空气组织、噪声与排水待下一阶段联核。

## 定稿覆盖：静音策略与设备间外形

2026-11-05用户确认分区原则定稿，设备与施工参数未定；本节覆盖前面把阁楼/短风管作为默认路线的候选写法。

- 全宅默认采用管道送冷、各房就地末端；不因为某处有阁楼就必须配置制冷风管。新风/排风单独安排。
- 普通房间末端噪声可接受即采用；屋主愿意投入大盘管、低风速、低速风机与隔振等定制静音路线，实际效果仍需选型核算。
- **老人房和卧室按最高静音优先级**；达不到目标时，把风机移至房外、可由走廊检修的设备柜，通过局部短风管和消声处理接入，避免夜间与检修打扰。老人房冬季主要靠无室内风机的水暖采暖，泵、阀与管路传振也须控制。
- 影院也按先争取安静末端、必要时局部风管的原则；片库以保存环境为先，机房以设备散热为先，各区不共回风。
- **L1-32空调设备间向南加深至与L1-33收藏室外包络的南墙对齐**：生成坐标u=-27.4..-24，v=9.2..13.7；刚性米制约3.40×4.43m、15.07㎡。南侧1.10m检修门同步南移，接收/检修坪随之缩短支路。L1-33仍为绕独立放映机房的L形，不是整块矩形；其实际面积约17.43㎡，所以两房面积亦接近。
- 设备间不与片库打通，扩大后留机组、阀组、消声/隔振和检修余量；不据面积承诺全宅负荷或所有机组已容纳。
