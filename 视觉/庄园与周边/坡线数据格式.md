# 地形工作台 · 坡线数据 v4

2026-11-04建立，2026-11-10补充适用范围。当前默认页仍沿用 `庄园三维体量模型_v3.html` 文件名，坡线数据格式已是 v4。本文说明基础坡线层；完整场景及其他地形/地表层见[三维地形与地表说明](三维地形与地表说明.md)。

## 场景规则

基础坡线层以平地（+1.2m）和湖盆为底，旧版硬编码山体不再作为这一层的来源。此后总场景已另行接入北岸脊谷、坝下河道与道路、南侧低丘、局部建筑场地和外围地形，也包含建筑白模、树林、裸岩及已建道路。它们独立于 `庄园坡线.json`，不能把当前整页理解为只有坡线和只读参考线。

基础坡线计算由湖盆和用户坡线组成：湖内使用湖盆高度，坡线不能填平湖水。删除全部坡线只会清空这一基础层，完整页面中的独立山体、河谷、场地和表面资产仍保留。

每条坡线是有方向的开放平面 Bézier 曲线。沿起点向终点前进，只有**右侧**生效：正北方向的右侧是东，正东方向的右侧是南。棕箭头显示行进方向，蓝箭头显示右侧；“反转方向”交换生效侧。判侧使用最近曲线点的局部切线，不用旧版最长线段或远处参考点猜测。端点切线之外不补圆头、不继续向外生效；折角须满足两侧切线的右侧判定。

多条坡线叠加取较高值，湖盆优先。单条坡线不会改变其左侧，但另一条坡线的右侧仍可覆盖这里。剖面末点之后保持末端高度，不再无限延坡。地形显示为有限分辨率三角网格，曲线边缘显示精度受网格限制。

## 总图参考投影

构建时直接从同目录 `庄园四岸总图.html` 提取非建筑部分，2026-11-10构建为 98 条线/轮廓及 42 个地名/取景点标注。保留道路、步道、马道、庄园边界、私人区分界、湖岸、水系、水坝及码头线、草坪/菜园/停车场/林地等地块轮廓、山体轮廓和林线。过滤具体建筑轮廓、立面窗线和建筑连廊；庭院草地等非建筑部分仍保留。

这些都是只读的描摹参考，不改变地形；改坡线/剖面后，按当前显示网格的三角形表面重新投影，避免参考线沿旧高度漂浮或穿地。水下标线投到水面之上便于查看。湖形和投影使用同一总图坐标，不保留旧版建筑落位所用的额外岸线偏移。

左上角“总图参考线”总开关；展开“参考图层”可分开显示道路、边界、水系、地块、山体/林线；“地名”单独开关，默认关闭，重叠标注会自动避让。标线包含山体椭圆轮廓只是二维示意参考，不是恢复西山实体或高度生成器。

## 两条曲线与预览

平面 `path` 直接保存少量锚点及相对切线手柄，不保存渲染用采样点。默认示例只有 4 个平面锚点，并非把旧的 34 个折线点逐点转换。

选“俯视编辑”后可拖动圆形锚点或方形手柄；手柄可以平滑联动或独立断开。右侧可以输入锚点 E/N 及手柄 ΔE/ΔN。双击曲线使用 De Casteljau 拆分增点，插点保持原曲线形状；也可末端加点、删点、新增/删除整条坡线。采样检测到的自交会拒绝应用，避免左右侧含义不清。

剖面 `profile` 仍由距离/高度锚点和相对切线手柄组成；“剖面曲线”按钮展开/收起编辑器。横纵轴视野独立导航，“适合高度”仅改变纵轴。3D 预览带距离只决定显示多深的半透明坡面，不改变地形数据或剖面编辑器的查看范围。

## 保存结构

```json
{
  "version": 4,
  "slopes": [{
    "path": {
      "type": "bezier",
      "points": [
        {"e": 0, "n": 1000, "i": [0, 100], "o": [0, -300], "smooth": true},
        {"e": 0, "n": 0, "i": [0, 300], "o": [0, -100], "smooth": true}
      ]
    },
    "profile": {
      "type": "bezier",
      "points": [
        {"x": 0, "y": 0, "i": [-50, 0], "o": [100, 0], "smooth": true},
        {"x": 600, "y": 200, "i": [-100, -40], "o": [50, 20], "smooth": true}
      ]
    },
    "preview": {"distance": 400, "visible": true, "color": "#e8a34e"},
    "editor": {"view": {"x0": 0, "x1": 700, "y0": -10, "y1": 250}, "selected": 0}
  }]
}
```

坐标均为米。平面手柄 `i/o` 为相对锚点的 `[ΔE,ΔN]`，剖面手柄为 `[Δ距离,Δ高度]`；两者的 `smooth` 均按锚点分别保存。剖面首点距离为 0，之后严格递增；平面锚点不要求坐标单调。

空列表 `{"version":4,"slopes":[]}` 合法，表示基础坡线层只保留湖盆和平地，不删除其他独立场景层。旧 `pts` 折线、`flip` 和 v2/v3 数据不支持，不再做迁移。

浏览器自动草稿使用新键 `zy.slopes.v4`，不读取旧键。下载得到同格式 `庄园坡线.json`；放回本目录后，在工作区根运行 `node toolchain/scene3d/estate/build.mjs` 重建默认页。当前静态服务器不直接写磁盘。`?cam=A/T/W1` 出图只用仓库内联数据，不读取浏览器草稿。

本地工具源码入口及验证在 `toolchain/scene3d/estate/README.md`；构建内联完整运行代码，可独立打开 HTML。

## 加载与查看正式地形

页面优先恢复浏览器草稿，因此更新仓库 JSON 后，旧的一条坡线草稿仍可能覆盖新的八条默认数据。左上角显示当前加载来源和坡线总数。

- **加载仓库存档**：HTTP 模式直接读取同目录最新 `庄园坡线.json`，绕过缓存；独立 file 模式使用页面默认存档。
- **加载 JSON**：选择本地 v4 JSON 文件，校验成功后载入全部坡线，立即重算地形和参考投影。无效文件保留当前内容并显示错误。
- 加载前内容进入撤销历史，并在浏览器 `zy.slopes.v4.before-load` 保存最近一次加载前备份；加载后的内容自动保存为当前草稿。
- **恢复页面默认**：恢复构建进当前页面的默认存档，和 HTTP 直接读取仓库的入口分开。
- **查看地图**：收起右侧参数及剖面窗口，隐藏坡线和半透明预览带，保留实际地形及总图参考；支持旋转、缩放和平移。**返回编辑**恢复操作面板。URL 加 `view=map` 可直接进入此模式。

地图投影仍由 `庄园四岸总图.html` 生成；要调整道路、边界、地块等位置，修改总图并重新构建即可更新投影，不需改动坡线设计存档。

## 二维底图与描线 SVG

“导出二维底图”可下载当前地形和光照的 2600×1800 正投影 PNG，可选带预览带、PNG 参考线。画幅与总图一致（0,-200 至 1300,700），没有透视变形或高程造成的横向偏移。

“导出描线 SVG”将地形 PNG 与参考线分层，保留原有 Bézier 曲线控制点；可在矢量编辑器中隐藏参考层、在描线层修改。文件自带底图，无外部图片依赖。修改后需回写总图并重新构建，目前不支持把修改后的 SVG 自动导入三维工具。
