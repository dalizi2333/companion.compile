# 庄园三维地形与地表

2026-11-10，用户接受当前阶段并要求整理归档。主预览为[庄园三维体量模型_v3.html](庄园三维体量模型_v3.html)；文件名沿用 v3，基础坡线数据格式为 v4。当前模型用于场景体量、布局、地形关系和取景检查，不是实测地块或工程设计。

## 当前场景

湖面为高度零点，平面 E 向东、N 向北，真南为 N 减小；Three.js 中 `x=E, y=高度, z=−N`。地域参考为挪威 Jølster—Førde，冬至设计计算取 61.5°N、6°E，不能把相对湖面的高度当成海拔或气候林线。

- 坝下公路沿低坡走廊连续下降，两岸干地高于河水。北向河流从 N2940 接续到实体远景北界 N19800，实际河床与外围山体共同切出贯通河谷。
- 北岸后山采用连续山肩、脊谷和独立林岩区域。林带大致位置保留，按坡度、坡向及邻域凹凸调整密度、树高和桦、松、少量云杉比例；岩缘加入断续低灌与矮树。
- 南侧为宽谷和两侧低丘，保留主楼的冬至采光开口。田后反坡宽槽、西牧坡脚斜楔已修顺，真实田地、牧坡及既建道路的保护范围保持。
- 用户红框所称“西南坡”按干草田、马场和既有林定位，实际范围约 E1100–1810、N610–1530。配置名沿用用户称呼，不能因此放到负 E 的既有 R01 大岩面上。现有 6 条林带、4 片岩面，坡脚接既有树林，山脊留草甸。
- 细节场地之外接渐疏实体地形，范围约 E−19.9～20.1公里、N−19.7～19.8公里。雾从2.6公里开始，前向深度12.5公里处完全融入背景，之后接低对比天空远山。早期“约4公里外直接接天空盒”和三层绿色山墙已被覆盖。

这些 JSON 与内联运行代码的 HTML 入仓；工具链及完整检查产物分别保留在工作区根的 `toolchain/`、`build/`，不属于此 Git 仓库。只克隆仓库即可打开 HTML；重新生成它需要本地工具链。北向出口和外围形态当前由本地模块定义，没有单独的场地 JSON，运行逻辑已内联在 HTML 中。

浏览器草稿键 `zy.slopes.v4` 只保存基础坡线。页面更新后若仍读旧草稿，可点击“加载仓库存档”；编辑林岩或低丘 JSON 后需重新构建。清空坡线不等于删除独立山体、河谷、建筑、树林或岩面。群落在加载时按地形生成，交互改坡只重新贴地；重载后才重算树种与密度。

## 最终验证

最终[验收摘要](../../log/北向河谷与南部接坡修正/最终验收摘要.json)与[交接记录](../../log/北向河谷与南部接坡修正/handover.md)随仓库保存，摘要含已验收 HTML 的 SHA-256。各阶段早期树数、网格数和日照时段保留在对应历史交接中，不能混作当前版本结果。

- 56项 JavaScript、3项 Python 测试通过；浏览器无脚本或着色器错误。
- 实际地表458个河道断面连续下降；河床最小水深约2.60米，检查的岸地最小高出水面约1.44米；内外地形接缝高度误差0。
- 六个近景确认河谷出口、两处接坡与林岩覆盖；外围可见边界均处于完全雾化区，最短前向深度约13.78公里。
- 冬至48个接收点按5分钟间隔检查。当地CET正午约12:34、太阳高度5.06°；主楼5个南向立面样点正午均可直射，主入口约10:49–14:14。庭院15个地面点均有日照，正午12/15；1.2米高度正午15/15。庭院中心地面约11:04–14:14。既有花灌木和老厕屋的局部阴影保留。

日照使用实际地形、实体建筑、保守不透光树冠和天空远山，不包含天气、落叶透光或室内穿窗；立面受光不等于室内日照。林地生态是地形代理的场景设计，不是实测土壤或生态调查。

在工作区根运行：

```bash

node toolchain/scene3d/estate/build.mjs
node toolchain/scene3d/estate/check-north-outlet.mjs
node toolchain/scene3d/estate/verify-south-uplands.mjs --corrections --outer --out build/北向河谷与南部接坡修正
```
